
现在继续研究位置随机化为什么有效，再针对有效机制扩大收益。最值得检验的假设是：让前面的决策保持原生选择，再对不同位置的理论原子进行相位扰动，改变了后续搜索所探索的模型区域。

但还不知道究竟是较后的决策更有价值、涉及的变量或约束组更不同，还是持续改变干预位置本身避免了重复探索。这三种解释需要区分。

## 一、先利用现有日志，做一次真正的机制分析

这次最有价值的条件是：位置 \\(K\\) 是随机选择的，Keep/Flip 也是随机选择的。

这意味着，已有日志实际上包含一个近似的 \\(4\times2\\) 对照结构：

| 实际位置 | KeepNative | FlipOnce  |
| ---- | ---------- | --------- |
| K=1  | 不改变原生相位    | 翻转第1个支持原子 |
| K=2  | 不改变原生相位    | 翻转第2个支持原子 |
| K=3  | 不改变原生相位    | 翻转第3个支持原子 |
| K=4  | 不改变原生相位    | 翻转第4个支持原子 |

这是我建议首先分析的内容，甚至不需要启动新的采样实验。

对每次查询，提取如下信息：

- 选择的位置 \\(K\\)、Keep/Flip动作、具体原子、涉及的整数变量和等式关联组。
- 该次查询的SAT/Unknown结果、完整成本、最终模型是否保持所选相位。
- 相对查询前覆盖状态的新增covered bit、首次单侧观察和零收益情况。
- 相对上一合法模型，有多少变量及独立约束组改变，以及这些变化对应多少真正的新覆盖。

以实际查询为单位，计算不同位置、不同动作的统计：

$$\
G\_=\mathbb E[\Delta C_q\mid K=k,A=a],\
$$

并分别报告SAT成功率、耗时分布和正覆盖收益的概率。

其中，\\(a\\) 为Keep或Flip，\\(\Delta C_q\\) 是本次查询及时交付的新增covered bit。

这里有一个特别重要的负对照：

如果没有改变相位的KeepNative组，其结果也随着 \\(K\\) 出现很大的系统性差异，就必须检查运行成本、状态分布及测量干扰。

如果只有FlipOnce出现明显的位置差异，那么“改变哪个决策原子”才有更直接的证据支持。

需要注意，虽然位置和动作都是随机选择的，但各次查询共享不断变化的求解历史，因此不能把几万个查询当成几万个独立实验，也不能由即时结果推断整个900秒的因果收益。统计要按会话、阶段和查询前覆盖状态分层，再综合7个seed。

## 二、我认为最值得检验的三个机制假设

| 假设                 | 为什么可能成立                             | 需要什么证据                                      |
| ------------------ | ----------------------------------- | ------------------------------------------- |
| H1：减少对相同原子的重复干预    | 第一个支持原子可能反复来自相近的约束结构；改变位置可能触及更多不同原子 | 新策略的不同原子、变量组、约束组覆盖范围扩大；新组出现后更容易产生正收益        |

| H3：改变增量求解器的搜索与学习轨迹 | 不同决策位置可能影响冲突、回溯及后续模型搜索，即使当次模型收益相近   | 不同位置的冲突数、SAT成本及后续若干查询表现不同；Keep与Flip存在可解释的区别 |

## 三、先定位收益来自哪里，再决定怎么改

我建议把分析分成两个阶段。

### 第一阶段：在旧日志中寻找规律

针对已有28次900秒会话，重点回答以下问题。

问题A：后面的位置是否真的更好？

分别比较 \\(K=1,2,3,4\\) 的FlipOnce事件，不只统计平均收益，还统计正收益概率、查询成本及Unknown比例。

如果位置2、3、4普遍更好，说明固定干预第一个对象可能确实不是好策略。

如果各个位置表现接近，但随机混合后的总体覆盖更好，那么真正有价值的可能是持续改变干预目标，而不是选择较晚的位置。

这会导向完全不同的算法。

问题B：被干预的原子是否更加多样？

建立稳定的原子和结构身份，检查：

$$\
\textw\text.\
$$

再比较重复干预和首次触及某个组之后，实际模型的互补性是否存在差别。

不仅要记录精确原子重复，还要记录“不同原子是否依赖相同变量或同一等式关联组”。否则可能表面选择了100个不同原子，实际上仍然在扰动同一小片结构。

问题C：收益是否主要来自少数突破性模型？

将每次正覆盖收益按实际出现顺序分析，尤其关注终止较长零收益区间的模型。

判断新策略的900秒优势究竟来自：

- 大量模型各多贡献1–2 bit；
- 偶尔提前得到一个新增几十或几百bit的模型；
- 或原策略长期停滞，而新策略较早切换到了不同的搜索区域。

这决定未来是要提高平均模型质量，还是提高“突破局部区域”的机会。

问题D：为什么优势逐渐缩小？

将查询和模型按0–30、30–120、120–300、300–600、600–900秒分段。

检查不同阶段的位置收益是否变化，以及较晚阶段是否越来越多地访问已经覆盖充分的约束组。

如果早期不同位置带来有效探索，后期这些位置也开始重复，就支持“干预目标本身需要持续多样化”。

如果后期仍然能改变新的约束组，但新增covered很少，则说明结构多样性本身已经不足，不能继续沿这条思路简单扩大。

还要先核查首次模型： 两配置的首次模型是否相同、首次成功前Unknown及预算轨迹是否一致。由于第一次相位干预发生在首模型之后，random的10秒退步有相当一部分可能与首模型时间差有关。不能把这些差异归因于位置选择。


## 四、如果H1得到支持，我最想尝试的改进是“结构新颖性驱动的位置选择”

当前算法是：

**在第1、2、3、4个支持原子中，等概率选择一个位置；到达该位置后，再等概率选择 KeepNative 或 FlipOnce。**

它只考虑位置，不考虑这个位置的原子与过去干预过的结构是否重复。

如果分析支持H1，也就是“随机位置的收益主要来自减少对相同结构的反复干预”，那么可以改成：

> **优先把一次软相位选择机会，用在最近较少被选择的变量或约束组上。**

### 1. 不只区分原子，还要区分它们涉及的结构

例如，两个原子写法不同，但都涉及同一组通过必要等式关联的变量。那么，连续选择这两个原子，未必意味着探索了两种明显不同的结构。

因此，需要为实际遇到的原子记录稳定的结构身份，包括它涉及的原变量，以及这些变量所属的等式关联组。

首版可以记录**最近64次已经选择的结构组**。这个窗口大小只是一个需要事前冻结的初始设置，不是已经验证的最佳参数。如果当前原子涉及近期较少被选择的组，就给它更高的选择优先级。算法设计思路

但这里仍然要注意：

**结构新颖，不等于一定能增加覆盖。** 它只是比“随机选一个序号”更有针对性的候选规则，最终还要检验真实新增观察和完整求解成本。

### 2. 必须采用在线规则，不能先看完再回头选择

求解器的决策是依次发生的，不能先观察前4个原子，再决定回头翻转第1个。

因此，首版可以使用这样的流式规则：

> 在前4个不同的支持原子中，选择第一个满足预先规定的新颖性条件的对象；如果前3个都不符合条件，就在第4个实施原有的 KeepNative／FlipOnce 选择。整个查询最多选择一次。

如果查询结束前没有遇到可以选择的对象，就保持正常求解，不回头补发干预，也不额外调用一次求解器。

所有新颖性判断只能读取此前已经发生的历史，不能读取当前查询未来的模型，更不能使用HighDiv保存的答案。

### 3. 只改“在哪里干预”，其他部分不动

与当前随机位置版相比，新版本唯一主要变化应当是**选择哪一个原子**。

以下部分全部保持不变：

- 原始公式、持久增量求解和完整模型阻塞。
- KeepNative／FlipOnce各50%的概率，以及每次最多一次选择。
- 查询预算、合法性验证、覆盖统计和立即交付。

这样才能回答：

> **有意识地减少结构重复，是否比随机改变干预位置更有效？**

它不需要新的SMT约束，不需要训练复杂预测器，也不需要重新构造覆盖下界。

**但是，应该先用旧日志检查结构新颖性与实际覆盖收益是否存在跨seed较一致的关联。没有这样的证据，就不应因为这个想法听起来合理而直接实现。**

## 五、如果H2得到支持，则研究“一次扰动是否不足以推动协同变化”

H2关注的不是重复选择了哪个原子，而是：

> **一次局部相位改变，是否经常不足以让多个关联结构共同变化，从而进入更互补的可行配置？**

如果旧日志显示，真正终止较长高原、产生较大覆盖收益的模型，通常伴随多个不同约束组的协同变化，那么可以提出一个进一步的机制假设：

**在一次查询中，以很小的额度，对两个不同结构组实施软相位选择。**算法设计思路

但不能从“高收益模型改变了多个组”，直接推导出“我们多翻转一次就能得到高收益模型”。这只是值得验证的假设，不是已经证明的因果关系。

### 1. 不能现在就把干预次数从1增加到很多

过去的实验已经反复说明：更强的干预可能导致更多失败、更多搜索成本，或者更差的后续轨迹。

因此，只有H2获得支持后，才考虑一个独立、最小的对照：

**原方法每次最多选择一个组；新方法每次最多选择两个不同组。**

仍然不增加硬约束，不固定其他变量，不要求两个建议必须同时出现在最终模型中，也不改变原生决策变量选择。

### 2. 评价的是实际覆盖，而不是变量变化距离

新版本必须同时检查：

**是否更容易产生跨组变化？这些变化是否真的增加覆盖？取得模型的成本是否超过收益？**

如果改变的变量更多、涉及的组更多，但covered bit没有提高，或者单位时间覆盖下降，就不能认为机制成功。

同样，如果两次干预经常落在高度重叠的变量集合上，也不能把它说成“两个独立结构组的协同探索”。

**这条路线要与结构新颖性选择分开验证，不要同时修改位置规则和干预次数。** 否则即使结果提高，也无法判断哪一项真正起作用。

## 六、下一轮怎样安排，才不会继续陷入反复试错？

我建议按下面四个阶段推进，而不是立刻开发一个包含所有想法的完整新版本。

### 阶段1：只读机制诊断

使用现有28次900秒轨迹，分析：

**位置与Keep／Flip的关系、原子及结构组重复率、突破高原的模型、不同采样阶段的收益变化。**

尤其要区分三个问题：

**较后的位置是否更好？持续改变位置是否更好？触及不同结构是否更好？**

这三种解释不能混为一谈。缺失的冲突统计、回溯细节或内部状态明确记为未知，不通过最终模型反推出不存在的搜索日志。

这一阶段不生成新模型，产出应当是：哪些证据支持H1、H2或H3，哪些解释不受支持，还有哪些必要信息缺失。

### 阶段2：做最小消融，区分“较后位置”与“位置多样化”

如果旧日志仍不能区分这两个解释，可以进行一次小规模对照：

| 配置 | 要检验的问题 |
|---|---|
| 固定第一个支持位置 | 保留原基线 |
| 当前均匀随机位置1–4 | 已有有效机制 |
| 事前固定的一个较后位置 | 检查是否只是较后位置本身更有利 |

较后位置必须在实验前固定，不能跑完多个位置后只挑最好的一个报告。

如果固定较后位置就能获得相近收益，那么主要问题可能是第一个位置不合适。

如果随机位置持续优于固定位置，那么“避免长期集中干预同类对象”就更值得研究。

这一步不同时加入覆盖评分、候选池或学习器。它的任务是区分机制解释，不是立刻寻找最优参数。

### 阶段3：只实现证据最强的一项改进

如果结构重复率与覆盖不足之间有较一致的关系，就实现前面描述的**结构新颖性驱动位置选择**。

如果主要证据指向跨组协同变化，而单次位置多样化不足，再研究有界的双组软干预。

如果发现主要变化体现在冲突和后续搜索状态，而现有日志不足以解释，就先补充必要的低开销诊断，不贸然开发新的评分器。

**不要把三个假设同时做成三个新模块，再组合出很多配置挑最优。**

### 阶段4：以当前最强版本为直接对照，在新seed上验证

新机制的直接基线应当是：

**当前已经取得长期收益的 `position_immediate`。**

不是更弱的plain，也不只是固定第一个位置的版本。

先做新的120秒配对实验，观察：

**同时间覆盖、前10／100／1000个原始样本覆盖、完整覆盖曲线AUC、候选供给、查询失败和新增机制成本。**

取得可重复的正面信号后，再冻结代码与参数进行900秒验证。不能因为两个开发公式的结果不理想，就反复修改窗口长度、位置范围和翻转次数，直到出现正例。算法设计思路

## 七、怎样才算真正“扩大了已有优势”？

当前位置策略已经比固定第一位置更好。下一项改进必须提供**相对当前位置随机化的新增贡献**，而不是再次证明它比plain好。算法设计思路

我认为需要同时关注两个目标。

**第一，让互补模型更早到达。** 尤其要检查random早期样本质量的风险是否减轻，而不是只在900秒最后多出几个bit。

**第二，让完整候选流获得当前版本尚未提供的观察。** 不能只是重排同样的信息，也不能只看变量变化数量增加。

同时，不能要求每个时间点都严格获胜，否则可能错过有实际价值的权衡。但如果早期损失明显、长期收益很小，就必须如实评价是否值得。

## 我的优先判断

**我会首先研究“干预目标的结构多样性”，暂时不回到复杂的Keep／Flip收益学习。**

原因是：当前已经验证有效的是改变干预位置；旧日志又包含随机位置和随机动作，适合进一步定位机制。相比之下，之前在线反馈学习相对同范围随机选择的增量较小，尚不足以成为优先扩展方向。算法设计思路

因此，我最希望下一步验证的是：

> **位置随机化之所以有效，是否因为它减少了对相同原子或相同变量组的反复干预？如果确实如此，能否在不增加求解调用、不增加干预次数的前提下，更有针对性地保持这种结构多样性？**

若得到支持，下一条主线就是：

**原式持久增量求解＋每次一次可放弃的软相位选择＋结构新颖性驱动的位置选择。**

若不支持，就不应沿这个方向继续加参数。**先查清现在为什么有效，再改进真正起作用的部分，比扩大位置范围、增加翻转次数或重新训练复杂评分器更值得优先投入。**
