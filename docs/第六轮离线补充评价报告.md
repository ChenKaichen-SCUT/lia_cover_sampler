# 第六轮评价口径补充：对已保存候选的离线重新评价

本轮从冻结提交 `13ed0d7` 新建分支 `round6-offline-evaluation-review`，只读取已有模型、检查点和运行记录。**原第六轮平均新增覆盖 Global 321.24、block 885.00 bit／动作的计分与报告保持原样，“停止扩大实验”的决定保持不变。** 没有修改候选生成器、Global 或采样策略，没有调用求解器搜索、优化器或采样器生成模型，没有重跑 HighDiv 或启动机制／端到端实验。

补充结果回答了三个问题。第一，Bromberger/prefix-1 已有种子可新增 7878 bit，两种模式各 18 个最终候选全部低于该种子，额外搜索未提供更值得占用一个输出位置的单模型。第二，把种子计入正式覆盖后，全部动作的平均真实剩余收益为 Global **116.46**、block **88.35** bit；此前 block 的平均收益优势没有保留。第三，三个保存候选有互补也有重叠，从种子已提交的状态出发，每会话平均联合剩余收益为 Global **223.94**、block **217.22** bit。后两项均是保存模型的事后价值，不是重新针对剩余缺口运行过的生成器表现。

**输入与及时见证复核。** 从 [原计划](../results/round6_block/main_60ms/plan.json)、会话输出、原始检查点和快照恢复六份 F、S、完整 seen0/seen1、种子 m 及正式去重集合。逐项核对计划、公式、文本赋值与类型化赋值、覆盖状态、归档成员、会话和检查点 SHA-256。完整状态与原分母保存在 [restored](../results/round6_offline_review/main/restored)；[审计记录](../results/round6_offline_review/main/audit.json)包含所有输入与输出哈希。360 个归档文件、72 个会话、216 个动作全部通过核验，缺失、损坏、孤立检查点及无法关联的来源均为 **0**，空的 [anomalies.csv](../results/round6_offline_review/main/anomalies.csv)仍保留。

六份快照的种子都**不在**正式集合 S 中；不能把这些种子当作已经消耗过的输出。每个动作只取原 `result.candidate`，与原最后一个及时保留检查点的完整赋值、原 gain 和实际写完时间交叉核验。没有按新增指标重选历史检查点，没有使用迟到模型。Global 2 次、block 14 次动作在已有见证后遭遇后续非 SAT 结果，其原及时见证仍保留。每种模式均为 36 个及时候选、72 个 `no_witness`，失败率 **66.67%**；无候选的 g_x、h_x 为零，直接候选差值为空。

所有覆盖都通过哈希冻结的 `ManualSatisfiesMetric` 求值，保留原 AST、短路访问、精确整数赋值、整数低 64 位和原分母。每条计算分支从独立的完整状态副本出发，不复用另一分支已经更新的可变状态。下文以新增 covered bit 数展示 f 的差值；换成覆盖率差时应按各自快照的原分母计算，不能将跨案例 bit 均值理解成百分比均值。

Bromberger/prefix-1 的候选相对种子的平均差 g_x−g_m 为 Global **−6196.22**、block **−2795.00** bit。即使 block 相对 Global 提高了原 g_x，两个版本的候选仍全部输给手中已有的种子。prefix-10 的种子收益为零，所有及时候选都提供更好的单模型选择。其他四个状态没有及时候选；其直接候选差值留空，没有把不存在的模型记为“低于种子”。

在已有 m 和保存的 x 中取最好单模型，全部动作的离线质量上界均值为 Global **1582.78**、block **1579.67** bit；两者中位数均为 72。仅使用已有种子时，g_m 均值为 **1541.83**、中位数 64.5 bit。这个上界对 `no_witness` 使用 m，对有候选使用 max(g_m,g_x)，因此不丢弃失败动作。它只说明保存候选集合中可选模型的质量，**不是新算法实测收益，也不是速度或吞吐率结论**。

同一快照的 g_m 在不同动作中对应同一个已有种子，只用于固定状态下逐动作的单输出位置对照；不能重复提交该种子并累加这些收益。会话联合计算只在起点 S′ 中计入种子一次。

原会话已记录种子加载、验证等初始化工作，但没有单独测量种子获取、验证、直接输出的完整即时成本。本轮将该成本标记为空／未知，不认为种子处理免费，也不从新增 bit 数捏造种子直接输出的速度优势。

**提交种子后的真实剩余价值。** 对每个动作重新构造 S′=S∪{m}，通过原评估器真正提交种子，再求值同一个保存候选，得到 h_x。逐条验证 `f(S∪{m,x})−f(S)=g_m+h_x`，无及时候选时 h_x=0。重复模型在更新后的覆盖与去重集合中贡献零。

没有将旧 `coverage_outside_seed` 列当作 h_x 的定义。本批完整重算后，二者恰好逐条相等，首次观察配对增加项为零；这不是一般恒等式。新增回归使用 `(or b (>= x 0))`：S 只含 b=true 的模型，x 未访问；种子 b=false,x=0，候选 b=false,x=1。x 的第 0 位由两模型合起来补齐，真实 h_x=1，而旧集合差列为 0。回归同时验证从空观察状态开始，两个合法模型的联合收益可以大于独立收益之和。

对全部 216 个动作，种子都实际观察了原主目标节点，但均不满足所缺的目标值；提交种子后，原主目标值仍然缺失。这里没有重新选择目标，也没有求解。Bromberger/prefix-1 的剩余收益下降反映了种子先补齐了大量其他缺口；不能据此说原主目标已经被种子实现，更不能把现有候选当成算法已针对 S′ 生成的结果。

**三个候选的联合价值。** 每会话严格按动作 0、1、2 的原顺序，最多追加每动作原保留的一个及时候选，并逐步去重、更新覆盖。分别从 S 与 S′ 开始，逐条核对顺序边际之和等于 U、U′。失败动作没有追加模型，成本仍保留；中间检查点没有进入集合 X。每模式 36 个会话，其中 12 个有候选，24 个三个动作均失败。

每模式的 36 个及时候选在各自会话内都互不相同，跨动作模型重复数为零；但每个有候选会话的联合收益均小于独立收益之和，说明不同模型仍覆盖了重叠 bit。24 个无候选会话两项均为零。代码没有预设联合收益一定较小，回归同时覆盖了联合收益大于、等于和小于独立收益和的情况。

候选也确实有互补。种子提交后，按动作顺序获得的平均真实边际如下，每行三个数之和等于对应 U′：

| 状态 | 模式 | 第 1／2／3 个动作的顺序边际 bit |
|---|---|---:|
| Bromberger/prefix-1 | Global | 350.67／166.33／249.33 |
| Bromberger/prefix-1 | block | 444.33／99.67／128.33 |
| Bromberger/prefix-10 | Global | 147.00／76.00／354.33 |
| Bromberger/prefix-10 | block | 311.67／36.67／282.67 |

因此不能说后三个动作只是重复同一份模型或完全没有互补；也不能把三个原固定 S 得分直接相加。prefix-10 中 block 独立收益和较低，但联合收益较高，说明这批保存候选的重叠程度较低。该状态的会话配对却只有 1 胜、2 负，均值改善没有表现为一致改善。**联合收益仅是已保存集合的离线价值，不能冒充覆盖逐步更新后重新执行生成器得到的在线轨迹。**

前置受限查询可能影响后续增量求解器历史，且某个模型在顺序联合覆盖中的边际依赖之前已追加的模型。因此上述来源表是保存见证及其顺序边际的描述，不是受限求解或全局回退各自的独立因果贡献，也不能据它推导移除某模块后的反事实收益。

本轮保留原“停止扩大实验”决定，不因某个离线补充指标变好自动晋级。下一阶段必须先明确场景：**种子未提交时，m 是已经拥有的合法候选或回退，新增搜索应与直接使用 m 的单模型质量和完整成本比较；种子已提交时，正式状态是 S′，生成目标必须基于更新后的覆盖状态。** 只有区分这两个场景，并补齐对应成本口径，才讨论是否值得开展新的候选生成实验。
