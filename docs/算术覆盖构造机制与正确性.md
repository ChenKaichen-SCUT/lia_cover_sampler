# 算术覆盖构造：机制与验证记录

实现遵循冻结协议，不改历史文件和算法入口。独立采样程序复制冻结 immediate 循环，只增加算术 prepare/capture/诊断；旧相位策略、RNG 消费、原 formula、完整 blockers、query 授时、正常模型完成与交付均保留。默认关闭的 CMake 选项为 `LIA_ENABLE_ARITH_COVERAGE`。

## 数学与生命周期

内核只在原 final_check 全部通过、即将 FC_DONE 时消费一次机会。原变量通过已有 enode/theory_var 映射，绝不调用会 internalize 的 expr get_lpvar。Bool 必须已赋值，Int 列必须整数且无 epsilon；当前不支持的别名恢复直接回退。按固定基关系，非基 j 增加 h*k，basic i 减少 a_ij*h*k，步长与可行区间复用原 int_solver。先检查所需行/列数量与有理系数，再调用原设施；有限界用 GMP 精确 ceil/floor 转 k 界。方向仅暂存在同步栈上。

完整原式和所有当前已赋值 relevant Boolean/theory atom 的真值在影子数值上复算（包括 disequality、blockers、assumptions 引入的原子）。当前无法纯值解释的状态不入池。外部桥再次对完整模型身份检查历史生成 blockers；正式程序除原式和完整 blockers 无其他动态限制。不得把自由区间本身当作 Q_t 的合法性证明。

R/C 共享提案算法：有限邻近点、有限端点、±256 代表窗口随机点、两个结构仿射 bit 的双值模命中。结构目标列表按原 AST 建立，最多256项；每列最多选两个。原 `math.hpp` 的 SHA 绑定私有副本使用 GMP，不创建 SMT AST/新查询。零步长先排除再周期裁剪；bit63 使用精确 2^64。整个池按完整原赋值去重，no-op 在0号。池达到16是完成；预算中断必须 no-op。

新增流与旧机制分离。R 在完整池中均匀抽取，不评分；C 在同一正式历史上完整评分，按 covered/observed 字典序，no-op 平分优先。纯值计划只读原 AST 元数据，在 check 之前懒构建并计费；回调不调用 Z3 API、不创建 AST。C 评分中断不保留部分最优。所有候选均不更新正式覆盖。

非零提交核对 epoch、列数、非基身份和起点值，使用原 set_value_for_nbasic_column；失效模型相关缓存、核查受影响行/界/整数性，返回 FC_CONTINUE。立即不变量失败中止并保存完整 SMT2 replay，不做不完整数值回滚。正常后续 random_update、assume_eqs、回溯/UNKNOWN 保留；日志分别记录诊断推荐候选、实际 committed_move、最终赋值和存活比例。probe 的推荐是影子 C 选择，内核实际选择始终0，不能把推荐存活解释为内部提交成功。

## 成本与局限

动作软限额2ms含当次计划准备；纯值计划分段准备均计入累计5%，未完成不安装hook。回调预算扣去内核已用时间。解码、去重、评分、构造、提交、API日志与磁盘诊断全部计入，且包含在完整会话墙钟。不可中断的单次大整数/分配可能超过软期限，超支真实记录。失败阶段的时间也记录；分项嵌套不能与完整hook再重复相加。

第一版保守处理无法映射、非支持运算、NLA、相关未知变量、epsilon。它们是支持率/接入证据，不是无解证明。一个支持列没有非零整数移动，也不表示多列联合移动不可能。

## 验证范围

新增 C++ 微型回归覆盖：255互补和式、2/3分母整数步长、固定变量、离散分支、disequality与逐模型blocker、别名链、有限域独立数学oracle、once latch、零动作预算、push/pop/reset与UNSAT、候选池与选择流隔离、词典序/no-op规则；纯值评估逐节点对照原评估器，包含负数、超过64位、短路和共享项。固定工作量微型测试使用独立1秒上限，不作为正式性能数据。原模命中穷举回归直接复用。

最终实测通过/失败、完整命令和 sanitizer 结果以 `results/arith_coverage_v1/correctness/` 为准；本说明不提前宣称测试已通过。历史 off 兼容性须对旧原生库固定操作模型序列、关键相位轨迹进行核验。

## S0 原有 search 回归的测试限时修正

首轮 sanitizer CTest 中新增 hook 回归通过，旧 search 测试在“0≤x≤3 的符号 bit=1 应为 UNSAT”处失败。独立诊断让同一测试分别加载冻结旧库与新库：两者均在50ms授时后返回timeout/canceled（完整记录在 correctness/search_failure_review），没有 sanitizer 内存或未定义行为报告。该断言检验逻辑证明及冲突缓存，不是50ms性能门槛。仅将该测试的请求/授时改为有界2000ms、父预算3秒，仍严格要求UNSAT和缓存生效，错误消息补上状态、原因及实际授时。原测试与失败日志保留；正式查询策略、新机制2ms限额、5%额度以及S1/S2/S3会话预算均未更改。
