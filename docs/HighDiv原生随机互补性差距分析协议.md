# HighDiv—原生随机互补性差距：冻结离线协议

基点ef3e9a7，分支highdiv-complementarity-gap。只读两公式的8条plain/native正式轨迹及2条历史HighDiv轨迹。禁止启动采样器、HighDiv、原公式求解或优化器；所有解析/评测在禁用search入口的环境执行。历史文件只读，缺失原文件从绑定哈希的原归档恢复到本轮新目录，不向原目录回写。

## 观察和来源

使用冻结ManualSatisfiesMetric从空状态求值每个完整合法赋值，获得每个原AST节点的seen0/seen1；Boolean宽1、Int低64位，未访问两侧都为空。按原AST先序编号及累计位偏移无损打包O(m)，分母保持104639/66061。保存位布局、公式/模型/观察哈希、原记录身份、写完时间、输出顺序和全部排除记录。重放所有已保存前缀的covered/观察数/状态指纹及900秒终点。原生的时间来自commits；HighDiv来自冻结补丁在samples.flush后写出的times.csv，不伪造更高时间精度或内部生成来源。

模型身份和观察身份分别记录；不同赋值但相同观察仍保留为不同生成事件。候选池选集只允许不同模型身份。HighDiv每公式只有一个历史seed；与两条native比较不构成两个HighDiv重复。主分析不跨seed混池；仅另列native两个seed合并的900秒信息上界，明确不是任何单次运行。

## 固定分析

1. 按公式和native seed精确计算HighDiv独有、native独有、交集及合并后新形成的covered集合。每个独有bit记录对方的unvisited/only0/only1，以及双方首次0/1的真实模型见证。两个前缀各自covered数量之差不替代集合差。
2. 对HighDiv前2/5/10/50/100模型的每个covered bit，记录native首次0/1索引、时间及完成覆盖时刻。分别提供同样本数（native索引≤k）和同时间（native时刻≤HighDiv第k模型写完时间）的早/晚/未完成分类；未出现记right_censored_900，不能推断不可达。
3. 每公式固定6个共同基底：HighDiv前2/10、native seed0前2/10、native seed1前2/10。对5条保存轨迹（H、N0、N1、P0、P1）全部模型评分；同一基底的评分严格从同一个完整状态开始。保存每模型真实增益、首次观察及基底身份，并汇总中位数、p90/p95/p99/max。所有混合评分均为离线诊断。
4. 扫描HighDiv前10模型中全部正增益事件，不事后选择增益门槛。以事件之前的HighDiv前缀为共同基底，对每条native全部候选计算增益，记录达到事件增益的真实模型数及首次到达；记录新增covered集合与事件新增集合的交集、差集和Jaccard，数量相同不能当成相同信息。按增益排序的前三个事件用于详细结构解释，正事件全部保留。
5. native各自截止30/120/300/900秒的池，k固定2/5/10/50/100，分别固定真实首模型或允许重选。每条池只做两条有界选集路径：固定首模型时穷举第二模型；自由首模型时从至多32个按候选到达顺序等距选取的锚点与全部池模型检查不同模型对，再以真实联合边际covered、其次新增观察、最后原索引较早为序贪心延长到100。未完成k只使用实际可选的至多k个模型。零covered增益但有新观察的模型可被保留，两个首次观察的配对不被当成零价值。
6. 全部池联合covered是真正的有效上界；另外单列HighDiv前k目标集合与池covered的交集上界。固定首模型的k=2穷举是该条件下最优，自由k=2仅在锚点覆盖全部池时才有最优证明。其他启发式结果始终是可实现下界；下界未达目标且上界未排除时为unknown。首版不调用任何有限选集优化器，不把启发式失败说成缺乏潜力。每个子集保存索引和完整身份，并由原评测器重新算真实联合覆盖。

上述32条选集路径（4条native×4截止×2种首模型条件）共160个k检查点。只使用本池截止之前实际交付的模型；从900秒池选出k个模型只能称为事后潜力，不能移到实时前k或早期墙钟表。

## 结构解释与判定

节点类型互斥划分Boolean、原Int变量、算术表达式、补充的整数常量；整数位段0–7/8–31/32–63，Boolean单列。新增观察按互斥优先规则分成首次节点访问、已访问节点的首次单侧bit观察、补齐相反值；另计重复观察。首次访问按节点另给数量，不能与bit数相加。冻结评测器的一次Int访问观察全部64位，因此中间类别通常为0，仍明确报告。

结构元数据保存原变量依赖、无条件等式与全部语法等式的关联组（分别标识，不把分支等式提升为全局约束），以及可识别OR分支中变量=整数常量的合取模式。赋值计算的模式选择只作相关性描述，不能改变原评测器的短路访问。代表性模型保存相对明确参考模型的全部变量变化、等式组及模式变化，以及具体观察差异；HighDiv内部生成模块一律unknown。

最终按公式/seed/前缀和900秒分别给A（具体已有子集/同基底强模型存在）、B（信息存在但需要更多模型；若无有效少量模型上界，只能作为现象而不是证明）、C（保存流缺少HighDiv有真实见证的信息）、D（上下界或证据不足）及组合。固定到达池的全部联合覆盖不随重排改变。已全部及时输出的900秒终点缺口不能通过只重排补上。A/B/C均只针对固定保存流，不推出算法能力上限。没有自动新策略、概率调整、学习或采样。
