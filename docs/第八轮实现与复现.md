# 第八轮实现与复现

新增 ChoiceCatalog、MacroChoiceGenerator、PlateauTracker 和独立 macro_online_probe。第七轮 residual_online_probe 原文件不变；ResidualGenerator 只增加默认开启的探索回退开关，本轮入口关闭它，把 broad 机会独立分配。原 Global::query / query_at_least / explore 的函数实现不变。没有连接旧 block 扩张、polish、准备缓存或 MaxSMT。

目录以原节点编号保存整个常量赋值备选。根必要 AND 下的 OR 才可选择；非 XOR 使用全部实际满足备选，部分分析时绝不假定互斥。必要等式仅用于静态关联诊断。查询保留完整 F、scoped push/pop，无外部变量固定和排除；组合 UNSAT 与单备选证明分开。Timeout/Unknown 不进入不可行缓存。独立 RNG 不消耗微观目标随机序列。

完整覆盖与去重只在正式 payload 写完且在截止内后提交。两模块评分均用相同轮初覆盖；保存各自已验证检查点，再按 covered/observed 比较。后续失败保留已写检查点，但不能把超时后才写完的正式输出倒签。每条检查点有模块与轮截止、实际完成时间，未选广泛候选也有模型、真实收益与耗时。正式初始模型单独记为第一个样本。

PlateauTracker 同时给在线和离线入口复用。旧记录缺失的内部计数为 null；在线记录微观/广泛成本和失败/重复计数，停滞处理单独记 events。失败查询不是零收益正式样本。最终无增长段右删失；参考模型池仅离线标注已知可达缺口，线上二进制不读历史池。

Release 与 ASan/UBSan 均通过 13 项 C++ 和 90 项 Python 回归。逐项日志和最终二进制/源 SHA 在 `results/round8_dev/validation`。包括跨分支、成组等式、协同变量、非互斥、作用域 UNSAT、Unknown、无结构回退、零收益、重复、Boolean 与超 64 位整数、覆盖独立状态、及时见证和迟到排除、8 轮停滞继续运行、原始 Manual 差分。保留已有外部 Z3 泄漏抑制，未关闭泄漏检测。实现期间发现并修正时钟起点微差、互斥比较未计入静态操作上限和测试对任意探索模型顺序的错误假设；均在冻结实验之前。最终目录与离线提取的可靠组完全一致，操作计数更完整，见 catalog_verification.json。
