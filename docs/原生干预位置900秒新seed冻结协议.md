# 原生干预位置900秒新seed冻结协议

本轮依据新的实施指引开展明确授权的长预算验证，不使用上一轮自动晋级门槛阻止运行。基点091b6a7，新分支position-frozen-900s；算法固定75cd6b6的源码、Release/ASan二进制与Z3依赖。仅新增调度、离线审计、统计与报告，不改采样器。

两个已接触开发公式为SMT_random_LIA_ex14600_2600_100.smt2、SMT_real_LIA_ex8500_2400_100.smt2。每个公式使用seed 3、4、5、6、7、8、9，比较first_immediate和position_immediate，共14个配对组、28次900秒。新seed不等于新的公式评测集。

原公式、增量simple solver、Keep/Flip各50%、最多前32个原生决策、每次最多一次机会、首模型前不干预、完整生成模型阻塞、立即交付、独立位置RNG及K=1–4全部冻结。查询50/200/1000/2000ms、25ms处理预留、100ms交付预留、原5%机制保护不变。从共同释放时刻起计入加载、初始化、失败查询、补全、验证、记录与交付。内部或迟到模型不计正式覆盖。

任务顺序在任何结果出现前固定为seed升序、每个seed先random后real、组内first然后position。前7组和后7组分别组成一批。核对实际lscpu、affinity、cgroup后，预留编号排序最后一个完整物理核的两个SMT线程，分别供监督器与系统；其余7核14线程用于采样。第一批first映射工作核j的第一个线程，position映射工作核j+1的第二个线程；第二批整体轮换3个核，first改用第二个线程，position用j+2的第一个线程。下标循环取模。每个工作物理核恰有一个first和一个position，同组两配置处于不同物理核。14会话共同释放，批间屏障；这是14路逻辑线程、7个工作物理核，不是14个独立物理核。每个Z3采样进程保持单线程。

运行前保存主机/cgroup可用内存、CPU限额、磁盘空间、前轮120秒及900秒逐进程峰值RSS。统一按max(1GiB,历史最大RSS的4倍)估计每个采样进程内存，再保留3GiB余量。容量不足时在运行前统一减少完整配对组数，保存计算依据；不做性能校准，不依据覆盖结果调整并发。正常当前拓扑与内存预计容纳7组。运行时若总采样RSS超过20GiB、主机或cgroup剩余不足2GiB，整批对称终止并停止后续批次，保留失败证据，不自动改并发重跑。

固定时间点1/5/10/30/60/120/180/300/450/600/750/900秒；固定不同合法正式模型前缀2/5/10/20/50/100/200/500/1000。未完成前缀为NA，无正增益时首次正增益时间为NA。AUC用全部实际提交时间上的阶梯曲线精确积分，并以增益×剩余时间交叉验证，单位bit·秒。

统计单位为每个公式的7个seed配对。主指标900秒覆盖差；报告逐seed值、均值、中位数、胜平负。长期改善的初步判据固定为两个公式分别至少5/7严格胜出、900秒中位差均正。早期风险固定为任一公式10/30/60秒或共同前10样本有至少4/7负差；不足7个共同前缀则保留缺失和证据不足。判据达成也不自动启动新实验，不改K、概率或加seed。900秒正面且早期重复退步时标为“长预算收益伴随早期风险”。AUC及全部中间点、样本质量仍完整披露。

早期诊断使用同一时间t双方已交付数量的较小值n：共同前n覆盖差作为同数量质量项，其余覆盖差作为到达数量项，验证两项之和等于D(t)。同时列首模型时间、模型间隔与达到同前缀的时间。这只是观察到的精确分解，不是解耦因果实验。

观察集合始终基于原AST身份、短路访问、整数低64位、完整seen0/seen1。每个样本前缀按Boolean、原整数变量、算术表达式及整数常数，并交叉整数0–7、8–31、32–63位拆分；常数项保留以完整守恒，不把多个重叠维度相加。集合差、双方合并才形成的covered位均真正按完整观察并集重算。

HighDiv只在全部采样后读取冻结历史覆盖集合；单一历史seed不当7次独立重复。辅助旧缺口固定为HighDiv覆盖且旧native seed0/1均未覆盖的交集，不在线读取。本轮保存position独有、first独有、共同、仅合并配对、HighDiv双方各自未得及合并后仍缺两种集合。旧缺口补齐不代替净覆盖差。

分别记录最长无covered增长时间、连续零covered和零新观察模型段、最后300秒新增样本与covered位、完整过程CPU/RSS、查询授权、Unknown原始原因与相位到达率。两算法均即时交付，生成/交付轨迹仍独立审计，不能将少数未交付尾部算成正式覆盖。
