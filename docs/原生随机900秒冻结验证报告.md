# 原生随机900秒冻结验证报告

基于 `40874ea`，分支 `native-random-900s-frozen`。按用户最终指示只运行两个既定公式、seed 0/1、plain 与 native_random_one，共8个900秒会话。直接复用原冻结二进制和库，没有修改算法参数或重新构建。没有运行反馈学习、HighDiv或超过900秒的实验。

15个任务槽、共享CPU 0–14，实际8个单线程采样任务在同一个单调时钟起点同时释放；监督器使用CPU15。没有排队波次或为了填满15槽增加seed。每会话预算包含加载、首次求解、全部机制与失败、验证及输出成本。机器为8物理核/16逻辑核，不是15个独立物理核。

全部新会话由冻结 ManualSatisfiesMetric 独立审计。完整原式合法性、seen0/seen1、短路访问、整数低64位、分母、去重、写出截止、边际累计、原生动作及完整成本区间均复核；审计未调用求解器搜索。

## 有限结论

- SMT_random：900秒两个seed均有正面覆盖信号；native−plain均值 665 bit，胜/平/负 2/0/0。平均覆盖bit 12712.5→13377.5，平均模型数 2077→1807.5。同数量与早期风险按上表保留，不能只用最终产量解释质量。
- SMT_real：900秒两个seed均有正面覆盖信号；native−plain均值 212 bit，胜/平/负 2/0/0。平均覆盖bit 7275→7487，平均模型数 3280.5→3257。同数量与早期风险按上表保留，不能只用最终产量解释质量。

这只是两个已开发公式、每公式两个seed的冻结验证，不能推及整个bofill或LIA。与HighDiv的数值差异仅作历史参照，不作公平加速或统计显著性结论。本次仅到900秒，不能回答超过900秒是否仍有优势；不自动追加更长预算、参数扫描或新实验。
