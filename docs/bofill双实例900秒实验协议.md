# bofill 双实例 900 秒冻结协议

本协议在正式长跑启动前根据用户最新指示更新：HighDiv不用跑，直接引用此前覆盖率。此前三配置版本未启动900秒实验；两次HighDiv 3秒验证保留为既有正确性证据。基点 c758fadb0f3f18b9f3da4a21e0fcdcb29b6e043f；分支 bofill-compiled-sampling。两个指定原文件、三个种子 0/1/2、两个配置 plain_clean/choice_compiled，共 12 次 900 秒。SMT_real 原为 evaluation，本轮明确用于定向工程开发，不能再宣称未接触；历史清单不变。

输入及 SHA256：

- SMT_random_LIA_ex14600_2600_100.smt2：114fb8ac7228c36cc6124bd9f2d95fd16a3bf2d330c39e185e8145d56821de1f。
- SMT_real_LIA_ex8500_2400_100.smt2：9ff3c643c1756057b1f127c5818bf38c468761ad3d2dd742cf34e3511e0690ec。

固定先 random 后 real，各按 seed 0、1、2，组内两个配置同步释放、组间屏障。固定逻辑 CPU 0/2/4，并核验其物理核身份不同；第 g 组配置 i 使用 cores[(i+g)%3]。监督器使用 CPU 6，两个采样进程的 OMP/BLAS 线程数设为 1。每进程地址空间上限 6 GiB、单文件上限 1 GiB、禁用 core dump；两个配置相同。墙钟从同步释放开始，包含 exec、输入加载、编译、结构记录、初始化和所有生成及交付成本。900 秒发送 SIGTERM，额外 2 秒后 SIGKILL；清理不计入性能预算，晚到模型排除。轮询误差和实际信号时刻记录，不把结束时间强行写成 900。

HighDiv 不启动任何新运行。历史参考固定为 results/highdiv_time900 的 seed 0、900秒独立审计：SMT_random 为13504/104639（12.905322%），SMT_real为7639/66061（11.563555%）。原HighDiv外层-O0、12工作槽且实际九例并行，二进制 c3daea3dd7e50eedcbeca139f018f4ecf05d47c67aa606badf31fa89fed1859a。来源manifest、审计及输入哈希绑定在highdiv_historical_reference.json中。历史覆盖是描述性参考，不加入本轮三种子胜平负，不把同一个历史seed复制成三次独立重复。

新采样器 CMake Release，归档实际 -O3 -DNDEBUG compile_commands；使用冻结定制Z3 libz3.so（c66acd3c4743444ce90b255820a88a65cbeaa4bd13808ed59ac7be91721967ca）。两个模式均不设样本数量上限，不因1000个或高原停止；若达到安全资源上限、错误或完整模型枚举穷尽，完整披露，不补跑直至获胜。

新两模式共用一个 simple 持久增量求解器，从首次 check 到最终枚举不重建；共享 seed、50/200/1000/2000ms 升级、真实剩余预算授予及退出解释。保留 25ms 用于交付；尾部不足 1ms 不启动查询。编译规则与限额见设计文档，对两个实例完全相同，预处理和结构写出全部计时。plain 的共同生命周期不同于历史入口；choice 对 plain 的差异才可解释为表示变化效果，不把与历史数字的差异归为编译收益。

每个新 SAT 恢复完整原赋值、验证原公式、计算原 AST 观察、去重、完整写出后时间检查。只有及时正式输出更新覆盖。完整原赋值阻塞排除精确模型，停止原因不能是高原或 1000 个。完整 models/commits/queries、结构和成本原样保留。覆盖状态每次记录逐节点零一状态的 FNV-1a64 指纹用于逐模型快速差分（非加密来源证明）；最终完整 seen0/seen1 必须一致。原文件、模型及原始日志另用 SHA256 作来源证据。

独立评测在全部采样完成后运行，冻结 ManualSatisfiesMetric 在禁止 solver.check 等搜索入口的环境中重放所有完整原赋值；维持短路、低 64 位、分母。非法、缺失、晚到、重复及截止尾行逐条分类，绝不补全猜测历史模型。历史HighDiv未导出的内部重复及未记录的每次求解成本保持未知。绝对时间减共同起点，不用启动延迟估计样本时间。

从同一 900 秒轨迹提取固定时间 1/5/10/30/60/180/300/600/900 秒，以及前 2/5/10/50/100/1000 个不同合法模型。不足的前缀为未完成，不补零。共同覆盖水平使用每个实例全部六次最终覆盖最小值的 25%/50%/75%/100%（向上取整）；这是描述性数据派生阈值，报告阈值和参与数，不作为选择实例或改变参数的门槛。逐实例分别报告中位数、均值、逐 seed 胜平负和配对完成数，不跨实例汇总 bit 数。

分别判断固定时间覆盖、同数量覆盖和到达时间。只增加产量不等于提高覆盖；只有固定时间提升而同数量未提升，解释为吞吐改善；两者提升仅支持这两个已开发公式的有限结论。不选择最好 seed、不增添参数扫描、不以短跑输赢取消已授权 900 秒实验。短跑仅作合法性、时间证据和资源安全检查，不合并入正式统计。

复现：CMake Release 构建并运行回归（不用构建或运行HighDiv）；随后 `python3 scripts/run_bofill_900s.py --out results/bofill_900s --postprocess`。离线单独复核使用冻结环境执行 `scripts/audit_bofill_results.py results/bofill_900s --jobs 3` 和 `scripts/analyze_bofill_results.py results/bofill_900s`。运行计划绑定实际源文件、二进制、协议和输入哈希。原历史结果全部保持原样。

完整原始 runs 目录以逐运行无损 tar.gz 归档，必要时按50MiB分块，以适应Git单文件限制；保留原目录，不删除日志。archive_manifest.json同时记录分块和每个解压文件的SHA256。克隆后首次审计可自动恢复缺少的运行目录，验证哈希；不覆盖已存在目录。资源监测只在监督器核上执行，每秒读取/proc，单独保留原始记录。
