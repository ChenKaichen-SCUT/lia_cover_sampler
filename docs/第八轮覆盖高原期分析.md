## 可达缺口证据

参考池仅包含四份完整公式验证通过、时戳有效的历史正式模型。对于高原起点已观察一侧的 bit，只要池中一个实际模型提供相反侧，就标为 PLATEAU_WITH_KNOWN_REACHABLE_GAP；逐段 CSV 包含见证来源、行号、模型哈希、原节点、bit 和取值。完全未观察的 bit 不用两个未来模型的合并伪装成单模型正收益。否则仅为 REACHABILITY_UNKNOWN，绝非证明饱和。未来池只用于事后说明，线上代码不会读取该池。

`plateau_segments.csv` 同时记录零收益期间模式改变和恢复时模式变化。模式不变可能停滞，模式改变也可能零收益，二者都不能单独证明效率。每个正收益间隔都保留；需要研究长高原时可按 duration 或 zero_outputs 筛选原表，报告未事后改变定义。低速正增长仍在 positive_outputs 和完整 covered/time 曲线体现，不混成完全零增长。

历史终止为预算截止或外部 timeout_partial；旧运行内部 Unknown 与每段失败次数无法从正式曲线恢复。模型数差异影响每样本高原长度，所以同时报告墙钟和最终覆盖。跨批次时间仅描述原记录，不是严格重跑的速度对照。
