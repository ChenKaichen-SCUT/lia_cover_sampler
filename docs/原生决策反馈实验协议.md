# 原生决策反馈：运行前冻结协议

基点 6b54afe，分支 native-feedback-phase。实施指引原文保存在同目录。本轮新建独立 Z3 库和程序，保留所有旧报告、历史代码及 No-Go；不运行 HighDiv 或900秒实验，不增加目标约束、assumptions、选择变量、优化目标或受限查询。唯一附加断言仍是完整原变量赋值的精确阻塞。

## 四种配置及实验顺序

plain、catalog_random_one、native_random_one、native_feedback_one 共用一个新补丁库、原式持久 simple 求解器及相同验证和输出流程。三个实验配置在第一个及时合法模型之后启用；不筛选、重排或保留候选池。旧目录范围由冻结 ConditionalObservations 实现按相同上限构造；新范围不以目录或摘要保证为前提。目录用于范围标签，对所有非 plain 配置计入准备和5%机制成本。

每次 check 仅查看前32次普通原生决策，在第一个支持、未赋值、未被特殊接口接管的对象上选择 KeepNative/FlipOnce，各查询最多一个机会；Keep也用完额度。额度不是回溯状态，restart、回溯及同原子再次遇到不重置。只有原生已选变量的当前相位可改变，变量优先级、传播、冲突分析及重启逻辑不变。

先完成 Release、ASan/UBSan、原生补丁与全部适用回归。然后曝光：两个既定 bofill 公式 × seed0 ×四配置 ×30秒，8个会话。曝光只验证接口、支持机会、实际 Keep/Flip、反馈与成本；不按覆盖胜负筛选。若接口正确，确有旧目录外机会且两个动作产生反馈，则执行已预定的正式验证：同两公式 ×seed0/1/2 ×四配置 ×120秒，共24个会话。若接口或审计失败停止，不用性能参数变化修饰失败。

每批同一公式和seed的四配置在四个不同物理核心同步启动，整组结束后才启动下一组。四个模式对核心的分配按组编号循环轮换；同时最多4个采样进程。保留完整CPU拓扑、输入/可执行文件/库/代码哈希和启动时间。不得恢复15逻辑核并发。采样期间不编译、不运行独立覆盖审计；采样结束后离线审计可15路。

总预算从进程门控释放时开始，包括加载、首次求解、所有初始化与反馈维护。普通查询授权层级保持50/200/1000/2000ms，受父剩余时间截短，并预留25ms交付。准备后重新授权，特征中的授权时间采用实际最终授权。剩余不足时结束，不休眠等待或追加免费阶段。

## 支持范围与上限

支持当前原生整数等式、≤、<、≥、>及其否定，项仅为原整数变量、精确整数常量、加减、一元负和常数乘法。无法识别的辅助变量、非线性、其他理论或量词安全跳过。无需映射到原 AST 才可支持，但原 AST 索引缺失时必须标为-1；不伪造保证摘要。

固定4096条持强表达式引用的缓存，不清空重用AST ID；达到容量停止新增干预。单原子递归最多512个节点操作、深度64、128个原变量，系数/常量大小最多4096位（超限跳过，不截断整数）。每变量向原AST父方向至多64次入队；每原子相关节点并集最多128，合并至多512次访问。相关覆盖仅为经验输入，不保证会改变。热路径不 simplify、不遍历完整公式、不写文件、不调用Python或求解器；旧目录的规范化只在查询之间完成。

新增特征、元数据、学习及钩子维护累计超过会话总预算5%时，停止后续新干预并继续原式普通求解。记录退出原因和实际开销；一次有界操作可能跨过阈值，不能隐去超出部分。必要的结果记录仍保留；不能宣称其后恢复成从未介入的搜索历史。

## 固定16维特征（含常数项）

按以下顺序记录数值数组；所有截断仅作用于预测特征，不修改公式和模型。

| 索引 | 特征与缩放 |
|---|---|
|0|常数1|
|1|等式为1，大小比较为0|
|2|min(1, log2(1+原变量数)/8)|
|3|min(1, 最大系数/常量二进制位数/64)|
|4|原生真假：±1|
|5|当前被查看普通决策序号/32|
|6|min(1, log2(1+本次check至今冲突数)/8)|
|7|最近及时合法模型中该原子的真假：±1，未知0|
|8|上述真假是否已知|
|9|当前正式covered/原始分母|
|10|此前最多16次完整查询中交付新观察数为0的比例|
|11|有界相关节点单侧bit数/这些节点原始bit总数|
|12|有界相关节点未观察bit数/这些节点原始bit总数|
|13|min(1, 上一次完整查询区间秒数/2)|
|14|上次查询控制层是否归类Timeout（不是任意Unknown）|
|15|当前实际授予求解器的毫秒数/2000|

不使用实例名、seed、AST数字编号、未来覆盖或其他模式结果。原子具体真假求值不更新正式 seen0/seen1。规范表达式、原变量列表、原AST映射、目录成员标签独立记录供审计，不作为额外学习特征。

## 预测器与动作概率

每动作各一个收益、成本线性预测器，共四个输出；同动作共享16×16岭矩阵，λ=1（含截距），会话从空窗口开始。统一窗口仅保留最近256条已经执行且有实际决策点的反馈。增删外积维护矩阵，查询之间 Cholesky 求解。只更新已执行动作，未选动作的真实收益与成本始终空值。

真实收益=及时、不同、合法正式模型对查询开始正式覆盖的新增covered/原始分母。Unknown、重复、迟到或没有正式交付为0；这不是不可达结论。成本标签为完整相邻查询区间。Flip最终未实现仍标Flip。无选择点的查询没有动作反馈，但保留其覆盖与全部成本。

每动作累计至少8条已训练真实反馈前均匀随机；之后80%选预测收益/成本最高动作，20%均匀随机。收益预测截断到[0,1]，时间预测限制在[0.001,会话预算]秒。利用部分平分或预测非有限时选Keep。冷启动条件概率0.5；暖启动所选最优动作概率0.9、另一动作0.1，完整记录随机数、阶段与当时预测。随机对照始终0.5，不训练预测器；其占位预测值不作为预测误差数据。

## 完整成本与学习时序

第一个查询区间从会话0开始；其后在下一次准备之前建立边界，上一条区间包含其准备、求解（含钩子）、补全、验证、输出、阻塞、元数据与日志。上一查询的完整成本确定后，才在当前区间更新上一动作的反馈。因此当前区间也包含上一标签的训练和记账维护，不能把训练免费化或重复收费。最后的反馈维护/记录单列为尾部成本；所有区间+尾部=保存的会话elapsed。进程墙钟另记，输出写完时间独立判断及时。

记录 check 总耗时与其中嵌套钩子耗时，不能把二者相加。分别保存加载、目录/特征初始化、准备/安装、特征、预测、训练、捕获、模型补全、验证、具体覆盖、模型/提交写出、阻塞和日志成本。准备总项与其细项也不能相加。预测保存的是选择之前值；反馈在后续边界才具有完整成本标签，不用最终模型回填旧预测。

## 报告与判断

分别比较 native_random−catalog_random、native_feedback−native_random、native_feedback−plain，按公式和seed报告，不跨公式汇总bit数掩盖退步。统计30/60/120秒覆盖，前2/5/10/50/100/1000不同原始输出，缺失前缀标未完成；曝光只报告≤30秒。记录首模型/之后观察、模型供给、最长无covered增长、零新观察连续段、旧目录外实际机会、Keep/Flip和最终实现、冷启动/探索/利用比例、所选动作上的预测误差与完整成本。

不计算未选择动作真实遗憾，不把一次查询结果解释为某个原子的独立因果贡献。只扩大范围有效与收益学习有效必须分开。吞吐下降不以90%一刀切否决覆盖优势，但必须报告明显供给下降、早期退步和跨seed不稳定。若学习未胜随机，停止扩大；不据此增加容量、翻转频率、奖励权重或900秒实验。原历史 No-Go 不被本轮中间结果撤销。

选择问题的概念参考：[Vowpal Wabbit contextual bandits](https://vowpalwabbit.org/docs/vowpal_wabbit/python/latest/tutorials/python_Contextual_bandits_and_Vowpal_Wabbit.html)。本轮不依赖VW，不声称具备其理论保证或独立样本假设。

## 运行与自动停止

`scripts/finish_native_feedback_round.py` 先确认独立 sanitizer 库成功，再构建项目、完成两套最终回归并冻结构建证据。曝光门槛精确固定为：8个会话均审计通过；4个 native 模式会话各有实际选择点；它们合计出现目录外实际选择、Keep 和 Flip。目录范围对照没有机会本身不是接口错误。只按这个正确性和适用性门槛进入24个预定会话，不读取覆盖胜负来决定是否进入。

各阶段遇到构建、测试、身份或审计错误就停止，不自动重试采样或调整参数。流水线可输出报告及推送既定分支，绝不增加第三个性能阶段。运行中的状态保存在忽略的 `build/native_feedback/pipeline_status.json`，最终阶段证据在结果目录中冻结。可单独重放已经保存数据，不必重新采样。

```bash
python3 scripts/run_native_feedback_pairs.py --out results/native_feedback/exposure_30s --stage exposure --postprocess
# 仅在上述固定接口门槛通过后：
python3 scripts/run_native_feedback_pairs.py --out results/native_feedback/screen_120s --stage screen --postprocess
python3 scripts/report_native_feedback_results.py
```
