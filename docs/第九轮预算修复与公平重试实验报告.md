# 第九轮：预算修复完成，但当前宏观实现不晋级

本轮从 `af9b2c6` 新建 `round9-budget-fair-retry`。实现和实验协议在运行前冻结于 `15c08e1`（此前 `ad8e293` 独立提交失败复核与预算分类）。完成 48 次独立查询诊断、18 个连续机制会话及独立审计。**修补解决了预算实际到达与备选重复控制问题，也产生了真实宏观新模型；但普通探索在同样预算管理下明显更好，公平队列没有带来覆盖收益改善。因此不执行阶段 C 的 18 次 30 秒在线实验，不增加预算或实例。** 第八轮原始报告、计分和“停止扩大实验”决定保持原样。

未重跑 HighDiv，未重放全部 291989 个模型，未运行 900 秒实验；没有启用变量块扩张、polish、准备复用或 MaxSMT。没有改变原始 AST、短路观察、整数低 64 位、合法性或覆盖分母。本文中的收益均是新增覆盖 bit 数，分母仍为 **104639**。

## 1. 过去的取消能确认多少

第八轮 online_30s 有 99 个宏观 unknown/canceled，mechanism_400ms 另有 6 个。共复核 10010 条广泛查询记录。**这 105 条旧取消没有一条具备完整的“实际 timeout + 纯 check 耗时 + 外部中断标志”证据链**，因此没有倒填实际时限，也没有追溯改记为确定 Timeout。

可唯一关联的单宏观调用聚合计时中位约 50.11 ms，支持局部限时假说，但最短只有 2.11 ms；计时还包含 reason 获取/分类，不能直接当作纯 check。普通探索当时对类似 canceled 使用另一套分类和超时增长逻辑，这是源码确认的控制差异，不是原因完全相同的证明。详见[历史失败复核](第九轮历史失败复核.md)及 `results/round9_diagnostic/historical_queries.csv`。

先按失败次数/结构身份固定六个备选，再具体求值与标签：反复失败的 (68,0)、(7,0)、(41,0)，以及未查询的 (0,0)、(0,1)、(2,0)。有限模型池为 **同一个 SMT_random 公式四条历史记录各前 100 个及时模型**，共 400 个。五个备选有合法见证；(0,0) 仅为 NO_WITNESS_IN_POOL，不能推断 UNSAT。三个反复失败备选的历史见证均不同于旧在线种子且有正增益，例如 seed-0 对应 4970、5106、5076 bits。历史赋值、池和答案未输入新生成器，也未用于选取新实验中表现最好的目标。

## 2. 状态与预算修补是否真正生效

新增统一退出解释接口，保存 raw_status、raw_reason 和独立控制分类。只有 canceled 的纯 check 时间达到实际授予时限的至少 80%，且没有外部中断、会话截止或明确资源耗尽证据，才标 `suspected_local_timeout`，保留 `inferred=true`。截短尝试不消耗完整重试级别，所有非证明退出都不产生不可达结论。

预算级别固定为 **50 → 200 → 1000 → 2000 ms**。查询预算与检查点/最终写出预留分开；连续动作不再塞进旧的约 320 ms 上限。两个广泛配置使用相同预算管理器，所有准备、求解、补全、验证、输出成本计入。

阶段 A 对六个固定备选、solver seed 0/1、四个预算点独立冷启动，未让后一个点继承前一个点的求解工作：

| 请求 check 上限 | 查询数 | 完整授予 | check 平均耗时 | 完整进程平均耗时 | SAT / UNSAT / raw Unknown |
|---|---:|---:|---:|---:|---:|
| 50 ms | 12 | 12 | 50.23 ms | 106.42 ms | 0 / 0 / 12 |
| 200 ms | 12 | 12 | 200.21 ms | 255.24 ms | 0 / 0 / 12 |
| 1000 ms | 12 | 12 | 1000.22 ms | 1055.64 ms | 0 / 0 / 12 |
| 2000 ms | 12 | 12 | 2000.29 ms | 2058.97 ms | 0 / 0 / 12 |

48 条新取消都有上述实际计时证据，控制分类均为“疑似局部限时取消”，原始状态仍是 Unknown/canceled。**长预算确实进入 check，但独立冷启动在这些预算内仍没有求出模型。** 这不否定历史合法见证，也不构成扩大预算的理由。

阶段 B 中，旧排序宏观完整获得 1000/2000 ms 的次数分别为 25/10，公平宏观为 22/6；这些宏观调用的纯 check 均达到对应时限的至少 80%。普通探索同样完整获得 1000/2000 ms 共 6/210 次，后者有很多 SAT 提前返回，不能把“允许 2 秒”误写成“消耗了 2 秒”。三配置共有 113 次明确截短授予（普通 99、旧排序 6、公平 8），审计确认没有将它们记成完成更高一级失败。

## 3. 同预算连续采样的实际结果

阶段 B 固定 SMT_random 两份开发快照 prefix-1/10、solver seed 0/1/2，三个配置各六会话，每会话 **10 秒**。计时在公式加载前开始，种子先计入正式覆盖；两个起点的已有覆盖分别为 **57 / 5609 bits**，均未计入下面的搜索收益。每个及时不同输出立即更新完整 seen0/seen1 和去重状态，后续候选针对实时剩余覆盖计算增益。

按两个完整三配置组一批、六进程同步启动，三批之间有屏障。三批运行在 2026-10-24 **14:59:44–15:00:14 UTC**；同批开始时间跨度均小于 7 ms，所有配对在同一批中。没有与第八轮 15 路时间数据混作同条件比较。采样结束后才启动审计。

| 配置 | 及时不同新模型 | 正增益新模型 | 六会话收益之和 | 每会话均值 / 中位数 | 无输出会话 |
|---|---:|---:|---:|---:|---:|
| plain_fixed | 298 | 88 | 33340 | 5556.67 / 5305.5 | 0 / 6 |
| macro_budget_fixed | 3 | 3 | 12509 | 2084.83 / 0 | 4 / 6 |
| macro_fair_retry | 3 | 3 | 5051 | 841.83 / 0 | 5 / 6 |

旧排序宏观相对 plain 的配对胜/平/负为 **1/0/5**，平均差 −3471.83 bits；公平宏观为 **0/0/6**，平均差 −4714.83、中位差 −4718.5。公平队列相对旧排序为 **1/3/2**，平均差 −1243 bits。唯一胜出的旧排序 prefix-1/seed-0 不足以证明可重复收益。

plain 在六个会话的首次正收益时间为 3.85–6.19 秒。旧排序只在 prefix-1/seed-0、2 成功，首次为 7.27、8.25 秒；公平只在 prefix-1/seed-1 成功，首次为 9.67 秒。其余会话的首次正收益时间为空，失败率单独保留，不当作“零秒成功”。

## 4. 公平队列改善了什么，未改善什么

每个备选的 visits 与 attempts 分离；队列按“两次新备选、一次升级重试”，一般 Unknown 有界延后，单备选最多四个完整限时等级。默认关闭双组组合。原排序配置采用共同的当前未满足单备选、有限尝试保护和预算反馈，再以公平配置检验队列的增量作用。

| 指标（六会话） | 旧排序预算修补 | 公平重试 |
|---|---:|---:|
| 宏观查询数 | 146 | 293 |
| 平均每会话不同备选数 | 10.17 | 32.67 |
| 新备选 / 重试队列机会 | 旧排序统一队列 | 196 / 97 |
| 重复备选查询总成本 | 56.36 s | 51.59 s |
| raw SAT / UNSAT / Unknown | 3 / 6 / 137 | 3 / 51 / 239 |
| 及时合法不同宏观模型 | 3 | 3 |
| 有真实新覆盖的宏观模型 | 3 | 3 |

所有新模型都来自宏观查询，两个宏观配置本轮均未产生普通回退输出；plain 的 298 个模型全部来自普通探索。每次宏观 SAT 都产生了不同且有正增益的正式样本，但**公平版的三个样本集中在一个种子**，旧排序版分布于两个种子。

公平队列确实扩大了备选探索，降低了重复备选的总耗时；各会话单备选实际最多四次，未发现同一备选重复执行相同的完整超时级别。然而更大的探索范围还带来了更多失败/UNSAT，并没有改善覆盖。新 UNSAT 均来自完整 F 加单备选、无额外固定/阻塞的作用域；与有限历史合法见证表交叉核对，无矛盾。

三配置完整进程累计成本分别为 59.78、59.83、59.86 秒，基本相同。纯 check 累计成本约 53.82、59.08、59.02 秒。全部失败、固定/强制约束构造、选择、补全和验证成本保留在逐查询/会话表中；`costs.csv` 的 query_seconds 与其内部子阶段有包含关系，不能再相加重复计费。完整进程成本包含最终序列化和析构。

因此当前数据支持的是：**预算控制修补后宏观机制能够偶尔找到有价值的模型；普通探索在同样连续预算下更有效；公平备选选择相对旧排序没有覆盖收益改善。** 没有在新受控负载下重跑旧版，因此不能定量宣称某一修补单独造成了多少历史性能提升。来源关联也不等于独立因果贡献，增量求解的先前调用仍可能影响后续搜索状态。

## 5. 无适用结构的回退与初始化成本

空目录分发直接进入相同 plain 路径，不构造宏观求解器、不消耗额外模块随机数；受控注入测试中两条路径得到相同 50/200/1000/2000 ms 查询决策。真实限时轨迹不承诺逐模型相同。

本轮真实机制样本只有有结构的 SMT_random。其旧排序/公平目录识别平均约 1.05/1.16 ms，额外宏观求解器初始化约 2.61/2.76 ms；全初始化平均为 plain 50.73 ms、旧排序 55.23 ms、公平 56.75 ms，全部计费。首次求解器、普通探索求解器、宏观求解器仍分别初始化，种子赋值并不携带此前搜索学习状态。

**由于阶段 C 未获准启动，Bromberger 和 convert 本轮真实回退成本没有新测量。** 正确性测试确认了空目录兼容性和零宏观构造；不能据此捏造这两条真实公式的性能开销或无退化结论。历史同类成本也不充作本轮实测。

## 6. 验收与最终决定

Release 和 ASan/UBSan 各通过 15 项 C++ 回归；各完成 96 项完整 Python 测试，再通过 6 项针对性测试（其中一项新晋级门槛测试，合计 97 项不同 Python 测试）。泄漏检查开启，只使用既有精确外部 Z3 抑制项。

A 的 48 次运行、B 的 18 次运行均完整保留、正常退出；阶段 A 无新模型，阶段 B 的独立原评测器审计完成 912 次模型求值检查，全部通过。304 个正式新样本均及时且不同；迟到正式输出、迟到内部候选、重复正式模型、超会话截止轮次均为零。审计只解析、求值与一致性检查，没有搜索；完整覆盖状态及连续边际收益逐项核验。

冻结的进入 C 条件没有满足：公平版只有 seed-1 有正增益宏观输出；六个公平/普通配对无一覆盖胜出，平均与中位差均为负。旧排序在两个种子有见证也未产生两个种子的性能正信号。**正确性通过、预算排故完成、宏观生成可用性得到有限证据；当前实现在已测试的同预算机制场景下成本效益不足，不晋级在线实验。** 这不是对所有宏观采样方法的否定，也不把一个公式的结果泛化为普遍结论；本轮不靠加预算、加目标组合或换实例追求正结果。
