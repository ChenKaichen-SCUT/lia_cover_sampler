

# 下一阶段：原生决策机会与在线收益反馈

## 1. 基点与本轮研究问题

基于冻结提交 `6b54afe` 新建分支，例如：

```text
native-feedback-phase
```

保留全部历史代码、报告和原 No-Go 判定。本轮不重跑 HighDiv，不启动900秒实验，不恢复投影、整数选择编码、强制分支或额外受限求解。

本轮只研究：

> **在原式持久增量求解的一次正常查询中，当求解器已经选定一个可决策的原子时，根据当前状态选择“保留原生相位”或“翻转这一次相位”；利用随后实际获得的完整覆盖与成本更新选择依据。**

需要验证两个独立假设：

**假设A：** 不再局限于旧摘要目录，能够在更多
是否能映射到原 AST；
是否来自旧摘要目录；
不支持或跳过的原因。
```

若原子含无法解释的辅助变量、无法恢复来源的内部对象或不支持的理论结构，首版跳过，保持原生相位。

不能为了增加介入次数而强制 internalize 新表达式、创建新决策变量或增加断言。

**映射不到某个原 AST 节点，不等于不能使用。** 若它确实是当前已有决策，且表达式只涉及能够可靠识别的原变量，可以作为新的经验决策对象；但不得给它伪造原 AST 身份或保证观察摘要。

### 3.3 每次查询只允许一个可评价的决策点

为减少多个干预共享同一模型结果的问题，首版规定：

```text
首模型之前：不干预；
每次 check：至多选取一个决策点；
只检查前32个正常原生决策；
使用其中第一个可支持、未被传播赋值、未被特殊接口接管的原子；
在该点选择 KeepNative 或 FlipOnce；
之后本次 check 不再进行任何新干预。
```

无论选择 KeepNative 还是 FlipOnce，这次机会都已经用完。内部 restart、回溯和同原子再次出现不能重发额度。

若前32个决策中没有支持对象，正常完成查询，记录 `no_eligible_opportunity`。不能为了获得一个学习样本而增加求解调用或更换决策变量。

这项限制只控制干预规模，**不保证搜索路径或模型吞吐与 plain 完全相同**。

### 3.4 热路径必须轻量

原子分类、变量依赖和静态特征尽量缓存。决策钩子中不得遍历完整 AST、调用 `simplify()`、读取文件、执行 Python 或调用求解器。

采用有界缓存和固定操作上限；未能及时完成特征构造时返回 KeepNative。保存强表达式引用，正确处理内部对象生命周期，禁止将跨进程 AST 数字编号作为模型特征。

## 4. 第二项实现：用完整实际收益学习，而不是给下界重新加权

### 4.1 明确预测对象

新策略不预测“这个原子能够保证多少 bit”，而是预测：

> **在当前决策环境下，选择保留或翻转一次原生相位后，本次正常查询能够及时交付多少真实新增覆盖，以及需要多少完整成本。**

动作只有两个：

$$
a\in\{\mathrm{KeepNative},\mathrm{FlipOnce}\}.
$$

对每次被选中的决策机会，记录上下文 \(x_q\)、实际动作 \(a_q\)、动作选择概率、实际结果和成本。

只更新实际执行的动作。另一个动作的结果保持未知；模型给它的数值只能叫预测，不能作为真实训练标签。这属于“只观察所选动作反馈”的在线选择问题，不需要引入完整强化学习系统。[Vowpal Wabbit](https://vowpalwabbit.org/tutorials/contextual_bandits.html?utm_source=chatgpt.com)

### 4.2 使用少量、可解释的上下文特征

首版特征维数不超过16，包含以下几类信息：

| 特征类别 | 示例 |
|---|---|
| 原子结构 | 等式或比较、涉及原变量数、系数及常数规模 |
| 当前原生选择 | 原生真假方向、当前决策位置、目前冲突数 |
| 已有模型信息 | 该原子在最近合法模型中的真假，未知单列 |
| 当前覆盖状态 | 总覆盖比例、近期零新观察比例 |
| 相关观察潜力 | 涉及变量关联的原 AST 节点中，单侧缺口与未观察节点的有界统计 |
| 近期搜索成本 | 最近查询耗时、最近超时情况、当前授予时限 |

“相关节点缺口”只是经验特征，不是这些节点一定会变化的证明。

原子的具体真假求值不能直接增加覆盖；正式覆盖仍只能由冻结评测器的实际访问结果更新。

特征只使用当前输入与已经发生的历史。不得使用未来模型、最终覆盖、历史参考答案或另一配置的运行结果。不得将实例文件名、seed编号或 AST 数字编号用作学习特征。

### 4.3 选择一种小型预测器，不同时尝试多套真实决策机会中实施轻度干预。

**假设B：** 根据实际收益学习的选择，能够优于同样机会、同样干预额度下的随机选择。

不要把假设A成功当成假设B成功，也不能把更多相位改写当作覆盖改善。

## 2. 保留已有可靠基础，不改变可行解集合

继续使用原始公式和同一个持久 `simple` 求解器。首次模型按 plain 获取；首次完整模型及时输出后，才启用新机制。

允许加入的约束仍然只有现有的**完整原模型阻塞**。新机制不得添加目标约束、assumptions、辅助选择变量或优化目标，不得修改原生决策变量优先级、冲突分析、传播及重启逻辑。

所有及时、不同、合法模型继续按原规则输出。不能通过过滤、重排或候选池制造样本质量优势。

旧的条件摘要继续作为独立的逻辑证据和历史对照保留，但**新机制不以“具有可靠摘要”为介入前提，也不再把摘要下界当成完整收益预测**。

## 3. 第一项实现：从“预选少数原子”转向“实际原生决策机会”

### 3.1 修改实际介入接口

重点检查并扩展：

```text
dependencies/patches/z3_soft_phase.patch
include/soft_phase_bridge.hpp
src/soft_phase_bridge.cpp
src/soft_phase_sampler.cpp
```

现有补丁是在原生变量和相位已选定后，查询预先安装的原子表。新接口应允许在相同位置观察**当前实际决策原子及原生相位**，再返回：

```cpp
enum class PhaseAction {
    KeepNative,
    FlipOnce
};
```

接口名称和实现可调整，但行为必须明确：不换变量，仅决定这一次是否改变原生真假方向。

### 3.2 扩大可处理对象，但不盲目处理全部内部变量

首版支持当前原生决策中出现的、能可靠解释为线性整数关系的已有原子，例如整数等式、大小比较及其否定。不再只接受顶层常量二选一目录中的区分原子。

对内部原子建立稳定身份和缓存，记录：

```text
规范化表达式；
相位符号；
关系类型；
涉及的原整数变量；模型

首版采用**每个动作两套带正则的小型线性预测器**：

```text
预测实际 covered 增益；
预测完整查询成本。
```

可以使用窗口化岭回归：固定最多保留最近256条有实际决策机会的反馈，正则参数先固定为1。训练或更新在查询之间执行，不进入求解器决策热路径。

将收益按原公式覆盖分母归一化，特征缩放规则在实验前固定。预测收益截断到合法范围，预测时间设置明确的正下限，避免负值或除零。

决策分数可以使用：

$$
\widehat U(a,x)=
\frac{\widehat{\mathbb E}[\Delta C\mid x,a]}
{\max(\widehat{\mathbb E}[T\mid x,a],\tau_{\min})}.
$$

这是经验性排序量，不是覆盖下界，也不宣称它等于真实长期收益率。

暂时不增加第三套“成功概率模型”、神经网络、复杂策略优化或大规模特征搜索。

### 4.4 冷启动与探索

每个会话从空模型开始训练，不使用旧日志预训练。

两个动作各积累至少8条实际反馈前，按各50%的概率选择 KeepNative 或 FlipOnce。

之后采用固定的探索比例，例如：

```text
80%按预测单位成本收益选择；
20%在两个动作中均匀随机选择。
```

预测平分或数值异常时，利用部分选择 KeepNative。记录实际条件概率，不能把预测较高但没有执行的动作填入训练集。

如果整个会话没有积累足够反馈，明确报告“主要处于冷启动／随机探索阶段”，不能声称已经验证了学习评分。

参数在实验前冻结，不按照两个公式分别调整。

## 5. 反馈与成本：用事实训练，不做虚假归因

### 5.1 真实回报

查询开始时冻结正式覆盖状态 \(S_q\)。及时合法模型 \(m_q\) 的回报为：

$$
r_q=
\frac{
f(S_q\cup\{m_q\})-f(S_q)
}{
\text{原始覆盖分母}
}.
$$

Unknown、没有模型、重复模型或未及时交付时，本次**交付回报**记0，并保留对应状态。

这不意味着该相位不可满足或没有潜在收益，更不能加入不可达缓存。

最终模型没有实现被翻转的方向时，动作标签仍然是实际执行过的 FlipOnce，不能事后改成 KeepNative。

### 5.2 成本定义

保存本次查询从准备、预测、安装，到求解、验证、输出、阻塞和反馈维护的完整成本。给每个阶段明确计时，避免再次用 `check()` 时间冒充全部成本。

若采用相邻查询边界形成成本区间，应保证各区间不重叠、不漏计；最后一个区间单列。训练可延迟一个边界，以便使用已经完整确定的上一查询成本。

不把钩子成本同时计入 `check()` 和额外总成本两遍。

### 5.3 一次结果只形成一条反馈

每个被选中的决策点最多产生一条反馈。不要把同一模型的全部覆盖重复分配给所有碰到过的原子。

即使每次只有一个受控决策点，这个回报仍然是**整次查询在既有求解历史下的结果**，不能宣称已经测得该原子的独立因果贡献。

前一次干预可能影响后续学习和搜索状态。本轮的预测器只是一种有界在线启发式，不主张标准独立样本假设或某种理论遗憾界已经满足。

### 5.4 无决策机会的查询

没有实际支持决策点的查询，保留完整成本和覆盖，但不伪造一条动作反馈，也不把它归给上一次干预。

新增元数据、特征和学习维护若超过预设会话成本额度，例如总预算的5%，停止后续新干预，继续原式普通求解；不休眠、不追加时间。记录保护触发，但不能声称已经恢复到从未干预过的轨迹。

## 6. 四个对照，分开验证“机会范围”和“收益学习”

本轮采用以下四种模式：

| 配置 | 决策机会 | 动作选择 |
|---|---|---|
| `plain` | 不干预 | 原生相位 |
| `catalog_random_one` | 旧摘要目录中的对象 | Keep/Flip各50% |
| `native_random_one` | 扩大后的实际原生对象 | Keep/Flip各50% |
| `native_feedback_one` | 与上一行相同 | 在线收益／成本预测＋固定探索 |

三个非 plain 模式共用“前32个决策中的首个支持机会、每次最多一个决策点”的控制方式。`catalog_random_one` 是按新单点协议实现的旧范围对照，**不是冻结的 `random_soft` 原样重跑**，报告必须写清。

重点比较：

```text
native_random_one − catalog_random_one：
扩大实际可干预范围是否值得？

native_feedback_one − native_random_one：
实际收益预测是否优于同范围随机方向？

native_feedback_one − plain：
整个机制是否带来最终净收益？
```

不要只展示最后一个差值。

随机对照不必执行学习版特有的训练来人为增加成本。学习版承担自己的全部预测和更新开销。

四种模式使用同一份新补丁库、相同原式、模型验证和输出规则；独立策略 RNG 不得消耗原生 RNG。

## 7. 必须增加的验证

首先验证关闭钩子及始终 KeepNative 时，在固定操作额度的小公式上与原行为一致。然后进行有限模型集合枚举，确认干预没有缩小解集合或制造错误 UNSAT。

新增回归至少覆盖：

- 旧摘要之外的原生 LIA 原子能够被可靠识别，未知辅助对象安全跳过；
- KeepNative完全保留该次相位，FlipOnce只改变一次正常决策；
- 传播、特殊接口、回溯和重启不被破坏；
- 首模型不干预，每次查询机会额度不会重置；
- 没有支持对象时不制造学习样本；
- 训练只更新实际执行动作，未选动作收益始终未知；
- 超时、重复和迟到模型的交付回报正确，完整成本保留；
- 最终未实现翻转方向时不篡改动作标签；
- 不读取未来状态，不跨会话共享历史答案；
- 特征预算、缓存上限及异常数值触发安全退回；
- 原始覆盖、正式去重、写出截止和边际累计恒等式正确。

Release、ASan/UBSan、原生补丁测试及全部适用回归通过后才能开始性能运行。新库独立构建，不覆盖历史冻结库。

## 8. 实验分为功能曝光和正式验证

### 8.1 功能曝光

两个既定 bofill 实例、seed 0、四种配置，各30秒，共8个会话。

只检查：

```text
能否遇到旧目录之外的真实支持决策；
是否产生Keep和Flip的实际反馈；
原式与模型是否合法；
单点额度、生命周期、预测和日志是否正确；
新增成本是否可控。
```

这里不要求先覆盖获胜。若接口正确且实际工作，即进入预先规定的正式实验；若没有足够支持机会，应说明适用性不足，不能靠增加硬约束获得机会。

### 8.2 正式验证

采用：

```text
2个实例
× seed 0、1、2
× 4个配置
= 24个120秒会话
```

比此前60秒留出更多在线反馈积累时间，但仍是开发验证。全部参数在运行前冻结，不在曝光结果后进行性能调参。

每批运行同一实例和seed的四配置组，分配四个不同物理核心，组间屏障并轮换核心。不要再用15路逻辑核并发，让共享物理核和队列波次掩盖查询成本差异。采样结束后再独立审计。

总预算从输入加载开始，包含首次求解、特征准备、学习、求解、验证及输出。没有额外免费训练阶段。

不重跑 HighDiv，不自动启动900秒实验。

### 8.3 主指标

同时报告：

```text
30/60/120秒累计覆盖；
前2/5/10/50/100/1000个原始不同样本覆盖；
未完成前缀数；
原始合法模型供给；
首模型之后的真实新观察与covered增长；
最长无增长时间及零新观察连续段；
支持机会数、实际动作数、旧目录外机会比例；
冷启动与预测选择各占多少；
Keep/Flip次数、最终实现情况；
特征、学习、钩子和查询完整成本。
```

保持全部原始样本输出，不添加新观察过滤，不使用离线最优重排。

对预测器保存每次**决策之前**的预测值，查询结束后才关联实际回报和成本。可以评价已选择动作上的预测误差，但不能给未选择动作计算“真实遗憾”，也不能用最终训练好的模型回头评分并冒充当时预测。

## 9. 验收：不把更多介入、更多模型或更好拟合当成成功

本轮分三层结论：

**接口层：** 新范围是否确实增加了可以使用的真实决策机会，而不是只有目录更大？

**策略层：** 经验反馈是否优于同范围随机选择？若只扩大范围有效、学习没有优势，应保留这个区别，不能把全部收益归功于预测器。

**最终目标层：** 是否提高同时间覆盖和同样本数覆盖？模型吞吐下降只作为成本与风险指标，不再单独以“低于90%”否决已经取得的真实覆盖优势。

仍必须报告明显供给下降、早期退步和跨种子不稳定。若仅一个实例有重复正面信号，可以判断为有限支持；不能宣称整个 bofill 类有效。

若学习版没有胜过随机版，不立即增加模型容量、引入复杂强化学习、提高翻转频率或调整奖励权重。先报告反馈数量是否足够、预测是否有辨别能力、收益是否被额外成本抵消。

**这一轮的核心不是“把下界算得更大”，而是把两个职责分开：逻辑摘要负责它能够证明的内容，经验反馈负责预测实际是否划算。**

同时，预测必须发生在求解器真正遇到的决策机会，而不是继续等待少数预选原子。两项改变是否有效，由同范围随机对照和完整成本下的覆盖结果决定，不能预先认定会成功。
