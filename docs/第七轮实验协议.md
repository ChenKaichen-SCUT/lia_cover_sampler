# 第七轮冻结实验协议

本协议在任何第七轮开发快照采样之前冻结。基点为 `b2f3047`，分支为 `round7-residual-cardinality`。本轮是已有历史样本上的继续采样，不是从零开始的完整采样。旧的实验文件、固定覆盖三动作入口和原计分不变。

## 对照和实现

仅比较 `global_pack` 与 `residual_cardinality`。前者直接调用既有 `Global::repair()`，每轮至多 3 次目标查询、2 次目标包扩充，保留原冲突修复和包大小适应规则。后者使用独立 `query_at_least()`，复用单向激活定义，以 `sum(ite(a_i,1,0))>=k` 为临时断言，不把所有激活变量作为真 assumptions。k 从 1 开始，SAT 后按原模型实际命中数 c 跳到 c+1，最多 3 次查询。比较候选采用全部原始 AST 的真实边际覆盖，平局再比较新 0/1 观察数。UNSAT 仅登记窗口、版本和阈值，原合取冲突缓存不接收这种结论。

两侧共用原公式、原评测语义、同一目标窗口规则、完整模型验证、去重、覆盖状态和探索回退。种子先验证并提交一次；S0 包含历史前缀和种子，此后正式输出才记新增样本和覆盖。每轮内部正式状态不变，提交后完整 seen0/seen1、去重和版本立即更新。辅助变量不进入样本或分母。

窗口最多 8 个原节点-bit，只有恰好观察过一个值且尚未观察相反值的 bit 才能入窗。跳过常量、已覆盖 bit 和已正确证明不可达的单目标。统一用 RNG 有界随机池：最多 256 次节点抽样，整数位每第三次从低 8 位取，其余从低 64 位取；不足时最多检查 512 个轮转节点-bit 单元。按节点-bit 去重，不合并不同 AST 身份。窗口游标和 RNG 常驻，不按案例调参。首次观察不进主窗口；窗口为空或没有正收益见证时最多调用一次既有 `Global::explore()`，共享预算，绕过软 cooldown，保留其原阻塞与超时适应。新零覆盖模型可以提交，但不清零覆盖停滞计数。连续 8 轮没有实际新增覆盖即停止，两个模式相同。

## 时间与交付

会话 10 秒，单轮最多 1 秒，时钟从文件/公式解析、前缀恢复及求解器初始化之前启动。每会话只有一份 Formula、Coverage 和 Global。实际新定义（含 repair 内部扩充所需定义）计时，缓存命中不重复收取定义构建；不强制对照预编码整个窗口。所有在线日志与检查点写入计入会话时间。阶段时间可能嵌套，不能机械求和当会话总时间。

两侧为提交预留本轮剩余时间的 20%，至少 10 ms；搜索部分不使用该预留。单轮目标选择、编码、求解、验证和检查点共享搜索额度，最终验证和提交在本轮总额度中。不可中断操作可以超期，记录实际耗时，不补预算。未完成编码明确报告已完整编码的目标列表和完成标志，不把未编码目标计入阈值；当前实现遇到编码截止即停止该查询，不把部分准备误记为 UNSAT。

`checkpoints.jsonl` 保存每次验证后改进的完整内部模型；`rounds.jsonl` 记录每次 flush 完成时间。后续失败不删除已确认的最好候选。**内部检查点与正式输出是不同事件**：`models.jsonl` 的完整模型行写完才是正式输出完成时刻，`commits.jsonl` 保存对应完成时间和截止时间，只有及时、不同、验证过且选定的模型才更新覆盖。不能用先前内部检查点的时间给迟到正式输出回填时间。提交回执和状态更新的额外耗时仍计入总时间，即使在模型已及时写完后发生超期。文件 flush 表示操作系统接收完整数据，不声称每条输出都完成硬盘 fsync。最终摘要/进程退出开销通过外部 wall time 另报。

## 固定计划与来源

6 个已有开发快照：3 个案例，各 prefix-1 和 prefix-10；solver seeds 固定 0、1、2；两个模式；无重复重试，共 36 个会话/18 个配对。顺序按快照、seed 排队，模式先后按快照序号加 seed 的奇偶交替，最多 15 个单线程子进程同时执行。设置 OMP、BLAS 等线程数为 1，记录 CPU、负载、亲和性、环境、二进制和源文件哈希。复用既有并发，不校准。每会话外部 60 秒硬保护只用于不可中断调用/异常，超过预算的输出绝不计分。禁止重新运行失败会话以替换原记录。

计划及哈希在启动第一个会话前写出。原始快照校验 formula、prefix、seed、coverage、assignments 哈希。采样全部结束后才开始独立审计，不让审计抢占采样资源。第一轮核对 S0 和窗口一致；以后覆盖自然分叉，不强行同步目标。所有模型、原始日志和独立审计按文件哈希归档。

独立审计只使用冻结 HighDiv 原评测器的手工求值接口，禁用求解/优化器调用；保留原短路访问、低 64 位及原始分母。复算每个候选的完整合法性、真实窗口命中、所有正式提交的边际、首次观察、覆盖版本、去重和及时性，核对 `sum(marginals)=final-S0`。源文件原始整数不截断。未知/缺损单列，不补模型。

## 指标、统计与预先停止规则

主单位是一个完整会话。每个快照×seed 配对比较终点新增覆盖率百分点；案例均值先保留两个前缀的结果，再按每案例 6 对等权平均。总体统计 18 个会话配对差的均值、中位数和胜平负；同时报告逐状态均值、中位数、失败和无输出数量。两个前缀属于同一案例，多个正式输出不是独立实验重复。

报告实际累计轨迹、终点原始新增 bit 与覆盖率百分点、前 1/2/5/10 个新增不同输出的累计收益及达到时间。未达到标记未完成；只有双方共同完成的前缀比较质量/时间，不外推。另报各侧完成率避免只展示幸存者。只计独立审计通过的及时正式输出；任何失败会话保留在全体表；无法通过审计的收益保守记零。异常退出前已经完整审计的及时正式输出保留，但会话失败明确标记，不能据此作正常性能胜负。审计或来源不完整则本轮不晋级。

晋级同时要求：

1. 至少两个开发案例终点平均新增覆盖率严格改善。
2. 18 对终点差的中位数非负。
3. 共同完成的早期前缀无明显系统性退步。本轮将“明显系统性退步”预定义为：任一 k∈{1,2,5,10} 的共同完成配对中，至少两个案例的平均质量差为负；或配对质量差中位数为负且负差比例至少 2/3。
4. 至少 k=1 和 k=2 的共同完成质量比较均覆盖两个案例。若不足，只能称样本质量证据不足，不能宣称时间和样本质量两个目标同时改善。
5. 所有 36 个会话和正式输出的来源、正确性、截止审计通过。

未全部通过就停止，不扩大窗口、查询次数、预算，不换 seed 或去除零收益/超时。通过也仅建议进一步验证，不自动启动任何长实验或改默认采样路径。本轮不重跑 HighDiv，不启用 block、polish、准备复用，不运行 120/300/900 秒实验。

## 可重放命令

```bash
cmake -S . -B build/round7/release -DCMAKE_BUILD_TYPE=Release \
  -DZ3_PREFIX=/tmp/lia-highdiv-frozen/venv
cmake --build build/round7/release -j15
ctest --test-dir build/round7/release --output-on-failure
HIGHDIV_ROOT=/tmp/lia-highdiv-frozen \
  /tmp/lia-highdiv-frozen/venv/bin/python3 scripts/run_residual_online_pairs.py \
  --binary build/round7/release/residual_online_probe \
  --output results/round7_online/main_10s --jobs 15
# 运行器结束采样后才调用独立审计和分析；单独离线重放：
HIGHDIV_ROOT=/tmp/lia-highdiv-frozen \
  /tmp/lia-highdiv-frozen/venv/bin/python3 scripts/audit_residual_online.py \
  --input results/round7_online/main_10s --output /tmp/round7-audit-replay
/tmp/lia-highdiv-frozen/venv/bin/python3 scripts/analyze_residual_online.py \
  --input results/round7_online/main_10s --output /tmp/round7-analysis-replay
```

单会话入口：`residual_online_probe FORMULA PREFIX_VALUES SEED_VALUES MODE 10 SEED NEW_OUTPUT_DIRECTORY`。所有输出目录必须新建，不覆盖旧结果。
