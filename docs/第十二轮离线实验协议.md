# 第十二轮：已保存候选的离线复用协议

基点：8937f66dc45502a3c04e8c77bcc5b02c73a1c82b。分支：round12-saved-candidate-review。
本协议在计算第十二轮结果之前冻结。第十、十一轮分别分析，任何结果不修改原实验结论。

## 输入与禁止项

只读 results/round10_projection/main_10s 和 results/round11_projection/main_10s 的全部 27、18 个会话，包含零输出会话；不筛选 seed。原始归档、计划、运行清单、逐文件哈希、公式、prefix、seed 和独立审计绑定到冻结提交。原目录不写入。新增输入副本、结果、脚本均单独保存。
不运行采样器，不调用求解搜索/优化入口，不增加 SMT 约束。用 no_search 防护下的冻结 ManualSatisfiesMetric 解析原公式、验证完整赋值、计算短路观察、整数低64位和原始分母。所有分支独立复制完整 seen0/seen1。

首先调用原有审计的只读 audit_job，并对完整原始轨迹再次逐模型重放。对缺失、损坏、关联不唯一的证据明确记录异常并停止该会话的模拟，不补造模型。查询和候选以 cycle、origin、version 唯一关联；候选可用时间使用 cycles.writes.completion，必须 validated <= completion，timely=true 且 completion <= min(stage deadline, session deadline)。后续查询超时不取消此前的及时见证。正式输出位置只取具有及时 commits 收据的 models 记录。

## 预先固定的池规则

容量仅 4 和 8。按候选写完时间、候选原文件行号排序。在每个原正式交付位置之前处理所有已经及时写完的候选。初始正式集合中的模型和模拟已经输出的模型不再入池。身份相同的候选不刷新 FIFO 年龄；后续普通来源出现不能追溯改变此前来源可用性。池满后立即淘汰最早入池者，不查看未来收益。容量约束作用于保留池，当前原正式候选作为外部回退提供，不占额外保留槽。

在每个原正式输出位置，以当前模拟覆盖重新评分：新增 covered bit 优先，其次新增 0/1 观察数，完全相同时优先原正式候选，再按最早可用时间、原行号、模型哈希。选出一个不同完整模型，立即更新覆盖与去重；被选模型从池删除。若原候选已被提前选过、池又为空，则该位置空缺，不能制造新模型或新位置；输出数量不相等的最终比较标记 incomplete，不冒充同数量胜负。

主对照为 original、all_4、all_8、ordinary_retention_4、ordinary_retention_8。ordinary_retention 只允许 plain、extra_plain 的历史出现进入保留池，但仍提供原正式候选，包括原正式投影候选：这是隔离“额外保留投影候选”价值的对照，不能叫完全无投影。

另在投影会话计算 ordinary_strict_4、ordinary_strict_8：连当前原正式投影候选也不能选择，只允许及时的 plain/extra_plain 候选及普通原正式候选，用于检查所有投影来源的附加集合价值。可能存在空缺，严格报告输出数量是否相等；不得拿较少样本的对照宣称同数量优势。不跨不同历史会话交换模型。

没有新搜索，未来候选仍来自原历史轨迹。改变离线选择可能改变真实在线阻塞和后续搜索状态，所以模拟不是在线运行、历史时间戳不是新算法交付时间。

## 评价与实现校验

每个候选先用 Manual 从独立空状态求出观察掩码；这些只读掩码的 OR 合并精确等价于完整状态更新。加速评分不改变节点顺序或分母。对每个原候选核对日志边际，对每个模拟输出再次用 Manual 更新并逐节点比对掩码状态。记录观察构造成本、实际池评分/维护成本、独立复核成本，三者分开；池成本测量包含在线候选到达时应承担的观察缓存构造成本分摊，不能声称免费。保存原所有查询和进程成本；审计本身不计为原在线耗时，也不伪造吞吐率。

选择事件比较在同一个 S_t 的 covered/observations、covered 新增集合交集、观察交集、联合增益、先提交胜者后的落选者残余；联合收益必须实际 OR 后求值。首次未访问 bit 的互补可能使剩余收益以后上升，不假设单调下降。对每个落选候选沿后续真实正式状态重新评分，输出变化点及最终点；统计唯一身份和候选出现次数分开，不将不同时间的收益累加为可恢复总量。每个会话最后正式状态上，按首次可用顺序计算各来源不同落选模型的联合残余价值，作为不受输出数限制的集合诊断，不能当作池的性能。池中恢复收益按实际模拟选择时的边际记录，不作因果分解。

报告前 1/2/5/10/50/100 个原正式位置以及最终位置；同步列出实际模拟输出数、是否达到目标数。未完成值为空，不能补零。主胜平负以会话为单位，在同一轮、同一公式/模式/容量内跨 seed 汇总；位置不是独立重复，bit 总数不跨公式汇总成性能结论。报告均值、中位数、原始差值、池利用率、FIFO 淘汰、来源、容量敏感性和成本。

回归使用字面量合成合法赋值，涵盖短路、低64位、首次观察配对、独立状态、已提交种子、无候选、重复、晚到、后续超时但保留见证、严格历史可用性、FIFO、不刷新年龄、完全相同优先原候选、跨动作重评分、普通来源可用时间与严格来源对照。测试也禁止搜索。

## 冻结继续/停止规则

第十一轮为主确认，seed 0、1 成对；第十轮独立历史复核，不能当作第十一轮额外重复。
只有以下必要条件全部成立才提出在线验证计划：在至少两个真实公式上，同一个容量的 all 相对 ordinary_retention 的最终同数量差值在第十一轮两个 seed 都严格 > 0；另一容量不得在该公式的任一 seed 最终退步；前 1/2/5/10 的已完成位置不能在两个 seed 上重复出现负差（只单次的负差也原样报告）。ordinary_strict 检查单列，不替代上述保留价值判据。
任一必要条件不成立即 No-Go：下一轮将投影生成机制移出性能研究主线，不加预算、不扩投影、不再调参。若条件成立，还须报告维护成本是否合理、效果是否具有实际规模；本轮最多提出新的同预算在线验证计划，绝不自动运行。普通候选复用可独立保留为研究方向，不能因此保留投影求解器。不因结果改变容量、门槛或案例集合。
