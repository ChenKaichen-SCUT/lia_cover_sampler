# 实现说明

## 数学核心

math.hpp 使用 GMP 整数。floor_div、ceil_div 显式调用向下/向上取整接口。模命中用两个 floor-sum 的差计数，再二分前缀计数定位任意排名见证；不遍历巨大区间。测试包含超过 2^128 长度的区间。

局部区域用稀疏仿射行 row=0、row≤0 表示。严格整数比较增加 1；否定比较翻转方向和严格性；不等式、distinct 的否定按当前模型选择安全分支。Boolean 等价、xor 等固定子条件当前真假，形成安全蕴含，不展开 DNF。算术 ite 保留谓词；分支尚未固定的观察 ite 不用于局部仿射目标。

方向来源包括坐标、稀疏有理消元后清分母、小规模组合、完整等式检查过的历史模型差。消元限制约 150 ms、300,000 次系数更新及系数位数，超限只丢弃该来源。使用时再次检查完整 E*d=0，精确区间必须包含 0。

## 原观察契约

原公式用 Z3 标准 API 解析，以 And(assertions) 建根。原 DAG 首次先序编号固定节点身份。常规评分缓存同一样本内共享节点的值与访问状态，不改变记录集合；差分模式展开重复访问，逐事件核对原 Python evaluator。

正式覆盖是 seen0 与 seen1 的交集，Int 64 bit、Bool 1 bit，常量计入分母。完整模型验证另用原始 AST 声明逐项固定，不能创建错误类型的同名变量替代。辅助变量不出现在原观察 DAG。

## 全局上下文

一个 Global 只绑定一个不可变 Formula。节点编号、bit、期望值，加上该对象的固定 Reach 和原公式，构成完整目标身份。缓存不跨公式、不跨运行导入。共享节点 Reach 合并所有入边路径，保留短路与分支条件。

商变量和激活符号使用 Z3 fresh constants，避免重名。全局 solver 只保存 F 和目标定义，以 assumptions 求解并缓存集合 core；三元冲突不转换成两两边。另一个 exploration solver 才保存模型阻塞，它的 UNSAT 不进入全局缓存。

unknown、timeout、cancelled、resource-exhausted 保留 reason，不产生冲突。目标超时从 50 ms 增至 2 s，目标包 1–8 个；初始求解从 100 ms 增至 10 s，均受剩余预算限制。困难目标可在后续活跃集合中重试；没有每目标独立的难度预测器。

## 调度与输出

每轮最多 48 个活跃目标、32 个局部候选，局部批次约 250 ms 上限。方向按完整等式结构缓存并刷新；截距、松弛与区间每次重新计算。调度使用近期实际覆盖增益、成本和停滞轮数，每五轮预留全局机会。允许新增观察状态或停滞后的合法不同填充。

输出集合、候选、种子库是不同容器；种子可含已输出或未输出的模型，只有正式输出改变覆盖。无方向、局部锁死、局部不支持和原公式 UNSAT 分开处理。

单进程是协作式时间上限，解析和单次不可分操作可能超出；实验 runner 统一硬截止，保留 timeout_partial。progress.json 用临时文件和 rename 保存，硬终止可能缺少最后几秒尚未完成的阶段统计。

## 已修复问题与回归证据

1. 未打开 ofstream 的状态检查错误：改为 is_open，特殊名字/Boolean 只写完整 JSONL。最小回归 tests/fixtures/special_names.smt2。
2. Z3 context 曾早于 AST cache 析构，开发 v1 输出后发生堆损坏。提前声明 context，确保全部 AST 先析构；保留失败记录并补充 ASan/UBSan。
3. 临时小规模复核脚本共享 Python 默认 context 的线程发生崩溃；正式审计器改用独立进程。采样器不共享 Python context。
4. 差分工具曾为每个节点重复构建事件集合，导致大实例复核慢；改为每样本构建一次，比较内容不变。

失败重放包含原公式、赋值、种子、配置、源摘要和最近上下文，全局查询保留 check-sat-assuming。第一版没有通用 SMT 自动缩减器；已发现的问题使用人工缩减 fixture 与回归测试固定，不声称所有错误自动最小化。
