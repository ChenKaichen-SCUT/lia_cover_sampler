# 实验性首次模型保护

显式模式 `full_fallback`、`choice_only_fallback`、`eq_only_fallback`、`simplify_only_fallback` 在原模式后附加相同的10秒首次模型保护。plain 仍为推荐主线，不启用编译。旧 choice_compiled 保留 full 语义，未悄悄改为新策略。

从同一个会话起点计算10秒，包含载入、编译、结构记录、求解、恢复、验证与写出。首个正式模型须在该截止前完成写出；check 的超时裁剪还保留25ms交付时间。未交付则在原总时间剩余部分切换原式求解器。不会重新取得总预算，不注入任何历史见证。若总预算本就不足10秒，遵守总截止，不额外给回退时间。

回退接口先销毁旧求解器，再用完整原式重建。完整已提交原赋值全部加入 no-good，正式覆盖与去重集合不随求解器销毁。默认自动触发只针对零正式输出的首次模型阶段；接口在已有正式模型时同样保证覆盖、模型身份和阻塞连续性，由专门回归检验，没有额外复杂在线调度。

日志记录 fallback.json 的开始、结束、剩余预算、原因与重建阻塞数；每个模型和查询标记 representation；汇总分别记录 compiled、plain_fallback、plain 的输出数及边际覆盖。编译准备、失败查询、回退初始化、评分、写出全部包含于同一总墙钟。保护是工程容错，尚无实际覆盖性能优势证明。

回归用合成公式和预推进的单调时钟验证固定10秒阈值，不执行新的真实实例采样或调优10秒参数。该测试不应被解读为真实10秒性能实验。
