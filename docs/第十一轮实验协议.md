# 第十一轮冻结实验协议：投影机会与完整赋值去重修补

基点 833bca1，分支 round11-projection-fix。只修补已有投影机制，保留第十轮原始报告、结果与旧入口；不启动 HighDiv、30 秒或 900 秒实验，不引入新生成算法、目标选择或调度策略。

## 实现约束

ProjectionGuidedExplorer 新增显式开启的持久完整模型阻塞，默认旧行为不变。每个 SAT 完成全部原变量补全及原 F 验证后，先撤销临时投影作用域，再添加所有原变量至少一个不同的精确 no-good；成功登记后永久保留，候选即使未输出或晚到也阻塞。最多 256 条，达到上限停本会话引导，不清空重建。正式输出重复、此前内部重复、首次新候选分开记录。若求解器返回已阻塞身份，保留日志并关闭引导，防止重复重试。局部阻塞/投影 UNSAT 不是 F 不可达证据。

新 projection_fixed_probe 支持 plain_only、plain_extra、projection_fixed。使用第十轮完整普通优先、初始互补、4 个零收益和4次普通机会冷却规则，原反馈变量评分/独立 RNG/3变量/最近4正式历史不变。无待选池。投影重复、失败或较差时保留及时普通候选；所有候选使用同一正式 S。正式写完且及时后才更新完整覆盖和去重。

两个额外配置阶段上限统一 250 ms，最多一次 check，请求上限统一 200 ms，按剩余阶段及父预算向下取整截短。为阶段内补全、验证、阻塞、评估、检查点预留至少20ms，另外保留最终正式交付时间50ms。阶段含懒初始化、反馈分析、所有准备与记录。会话总额为10%，保留5ms尾部维护余量；不启动不足40ms的额外阶段。plain_extra 通过原 Global::explore 可选请求参数获得200ms，不额外创建第二求解器；该参数默认为0，原调用不变。普通查询原50/200/1000/2000ms适应层不更改。

实际原生操作可能跨越剩余时限；所有实际超额仍计入成本并单列。阶段超额不提供更多预算，若超出会话额度停后续引导；不得将非法、晚到模型计入正式输出。报告必须区分逻辑/覆盖正确性与墙钟额度是否全部兑现。

## 验证与冻结顺序

先新增持久阻塞/临时撤销/同投影多完整模型/256上限/大整数Bool/Unknown取消/预算截短/超过旧50ms准备后进入check等回归。Release、ASan/UBSan、已有完整回归与独立 Manual 检查通过后冻结源代码与以下参数。小型机制结果不得用于修改参数。

机制验证：三个原开发公式 prefix-1、solver seed0，plain_extra 与 projection_fixed，各一个固定状态组件会话，总成本0.75秒，最多16次250ms动作/200ms check，共6会话，同批六路。输入种子已提交，S与最近正式历史不更新，不新增正式模型；完整公式/恢复/求解器初始化计入0.75秒。此组件验证直接调用已有模块以核查重复阻塞及实际check，不运行在线触发调度，不能将其吞吐当作10%额外配额下的在线表现。两方同总预算/生命周期，所有失败与零收益候选保存。

组件正确性和日志审计通过后，执行唯一正式筛选：三个开发公式 prefix-1 × solver seed0/1 × 三模式 =18个10秒会话。每批两个完整三模式组（最多六路），同步屏障、模式顺序随seed轮换；采样期间不构建或运行审计。所有会话从相同已提交seed的状态开始。原第十轮仅历史参考，不混为本轮配对。

## 指标和决定

逐会话报告进程墙钟/CPU、初始化、普通SAT/查询数、额外查询和实际授予/纯check/原始reason/局部分类/父预算截短、完整阻塞成本和数量/停因、合法不同候选/正式重复/内部重复、投影正收益/严格赢家、输出/前1/2/5/10覆盖（未达保留为空）、10秒新增bit与原分母百分点、最长连续零输出/无覆盖增长时间。完整模型、写完时间、哈希、全部失败成本保留。独立审计只具体求值，不新求解。

会话为配对单位。必须同时比较 fixed-extra、fixed-only、extra-only，均值/中位数/胜平负和零输出均报告。实际候选供给=截止前验证的不同合法候选/完整进程墙钟，内部候选不计正式覆盖。

继续信号预定义为：至少两个独立公式上，fixed在两个seed的10秒覆盖均高于两个对照，并且各公式有及时正收益投影严格赢家；各公式平均不同候选供给不低于两对照各自90%，同完整前缀不出现两个seed均下降>10%或对照完成而fixed未达的可重复早期退步。任一非法模型/覆盖错误/截止倒签停止性能实验修复。时间超额全部报告，不能删会话补跑。

无论是否有信号，本轮均不自动跑30秒。修补调用有效但净收益不达门槛则判“修补有效、性能未通过”，停止扩大；只有上述跨实例正信号成立才在报告单独提出30秒验证计划，不执行。禁止事后增频/扩块/调权/加时。
