# 实验设计

- 数据：用户 benchmarks 九实例，保留 SHA-256。按哈希排序前三个作开发，其余六个作评测，不改写输入。
- 基线：一次批次，种子 0/1/2，每实例每种子调用一次；之后只复算已存样本。计时插桩不改变采样逻辑。
- 预算：每次 30 秒严格墙钟，最多 1000 输出；12 路并发，单求解器单线程。新方法四种配置按批次执行。
- 固定时间：0–30 秒每秒读取在线有效不同前缀的覆盖；空前缀覆盖为零，保留无模型状态。
- 固定样本数：k=5/10/50/100，只对双方都实际达到 k 的运行配对，报告可比较数量及达到 k 的时间。
- 过滤：统一接受新增覆盖、新增观察，或连续 32 次停滞后的不同填充。对 HighDiv 与新方法使用相同规则，不重复生成候选。
- 验证：全部完整输出逐个复核。缺变量、类型错误、重复、非法模型、缺时间戳分别统计。最后不完整行不作为完成样本，保留原始字节。
- 覆盖：冻结 evaluator 处理所有合法样本，与新程序各前缀的覆盖整数值比较；每次运行前五个前缀再比较完整状态和事件。
- 编译：新方法 -O3，HighDiv -O0。遵从“不再运行基线”，不添加 O3 对照；不声称隔离了编译级别。
- 时间：显式写出时间戳，不用文件修改时间。过滤时间为串行成本重建，未测在线竞争开销。
- 失败：timeout_partial 不是正常完成，样本数不足不是相同 k，局部不可达不是全局不可达。

这是九实例、短预算、多种子的第一轮机制对照，不替代 900 秒实验、全量数据或跨机器结论。全体九实例和事先划分的六个评测实例分别报告。
