# 条件观察评分有效性诊断报告：只读历史日志分析

基点 `56cc9ef`，分支 `soft-phase-score-diagnosis`。指标与分组先在提交 `65607b9` 冻结，再计算结果。本轮只重放已保存赋值；没有调用求解器搜索、采样器或优化器，没有修改历史源码、库补丁、协议或归档。**原 No-Go 保持不变。**

## 结论

最明确的证据是**摘要描述范围不足，以及有分数的偏好很少真正进入原生相位选择**。正式软偏好会话中，92.82%–97.24% 的真实新增 covered bit 不在当时完整摘要目录可描述的缺口集合中；实际采用且最终实现的摘要只能解释 0.48%–5.70% 的覆盖增益。这是集合包含关系，不是因果贡献。

没有观察到首模型之后“全目录 covered 下界归零”；也没有观察到在线的“L 相同而 N 不同”或“L/N 完全平分但 N>0”机会。因此，“评分彻底耗尽”和“coverage 平分弃权、random 继续介入”都不是这批轨迹中得到支持的解释。部分实际介入没有在 SAT 模型中实现，另有 Unknown 无模型，但实现概率低并非统一现象。高成本主要出现在本次没有实际介入的查询；仅一个方向有同覆盖版本、同分数的连续 Unknown 重复。不能据此证明高分方向普遍错误，或者相位偏好与成本无关。
