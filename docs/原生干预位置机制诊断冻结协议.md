# 原生干预位置机制诊断：阶段1冻结协议

基点为 `7d3d2e7`，输入仅限 `results/position_frozen_900s/` 的28次900秒历史会话（两个公式、seed 3–9、first_immediate和position_immediate）。使用最多15个离线工作进程，不执行采样、求解搜索、算法修改或新的机制实验。阶段2–4作为后续候选路线；本次先交付机制证据及明确的继续条件。

所有读取的公式、模型、日志和旧审计结果绑定冻结清单哈希。原始运行目录缺失时，仅从旧归档恢复到本轮新目录。复用已通过冻结ManualSatisfiesMetric逐模型验证的观察集合，重新逐查询重放完整seen0/seen1和边际恒等式；新独立复核对固定规则选出的模型见证再次用原评测器求值。所有Python入口启用禁止solver/optimizer/fixedpoint搜索保护。

预先固定分析定义：

- 阶段按查询周期开始时间分为 `[0,30)`、`[30,120)`、`[120,300)`、`[300,600)`、`[600,900]`。收益为本查询实际及时正式交付的新增covered bit；失败或无交付为0，不能删去。首次观察与补齐相反值分别计算，完整合并不能用独立收益之和代替。
- 位置分配ITT统计包含所有获得K的查询；4×2动作统计仅包含实际到达并选择的事件。未选择动作记NA，不推测随机动作。动作是到达后才抽取，达到位置的条件性与先前求解历史须披露。
- 主要聚合单位是会话，再对同公式7个seed等权汇总。不给查询级独立重复的置信度或显著性。位置对照为K=2–4等权对K=1，并逐一保留K=1/2/3/4。负对照KeepNative及Flip减Keep的位置差共同报告。
- 状态调整只使用查询前信息：阶段、covered数量按250 bit分箱、授予timeout毫秒数、此前连续零收益查询数分箱（0、1–4、5+）。对照仅在两组均有数据的共同分层比较，以两组最小样本数作为该层共同权重；缺层为NA，报告支持度。该调整不能消除未记录求解器状态的混杂。
- 精确原子身份为公式哈希及解析后的完整表达式哈希，不使用跨进程local_ast_id/cache_index。变量依赖按精确线性系数消去后的原变量确定，并核对日志索引。必要等式组只合并顶层合取下的整数等式，不将OR/ITE内部等式提升为全局事实；组间仍可能由不等式或分支耦合，不能称为已证明独立结构。另保留直接变量集合身份、实际触及变量和重叠等式邻域。
- 新颖性只查看此前64次实际选择的历史（Keep与Flip均计入）。分别记录精确原子未出现、至少一个直接变量未出现、至少一个必要等式组未出现；再区分会话首次触及和窗口内重新出现。新颖性收益对照除上述状态分层外还匹配K位置，Keep与Flip分别比较。不使用后续模型或未来收益更新定义，64不是已验证的最优窗口。
- 相邻模型变化比较上一个已验证合法模型；第一个模型的变化数为NA。记录改变变量、必要等式组、原始等式邻域、新covered掩码及新观察，变化距离不是优化目标。
- 突破事件预先定义为正收益且此前至少30秒无covered增长；首个正收益（从空状态起）单列。正收益按1–2、3–9、10–99、100+分箱；报告全程和去除首10个正式模型的贡献，保留实际顺序、最长高原及末段删失。另报告每会话最大10次收益占比，作为集中度描述而非重新排列轨迹。
- H3只报告已记录的选择时conflicts及之后1/5次查询收益和完整成本；不足窗口记右删失，不补0。未来窗口有重叠且含后续干预，不能作当次动作的独立因果收益。不把选择时conflicts误称为全次查询总冲突或回溯次数。
- 必须核查首次模型身份、首模型前全部Unknown、timeout等级与实际成本；首模型前未启用位置干预，不把这一阶段配置差异归因于位置机制。

H1/H2/H3均为待检验解释。报告会话级胜平负、中位差、分层支持度及反例。若结构分组退化为一个巨大组、共同分层不足、Keep负对照亦不平衡或相关性跨seed不一致，明确保留证据不足；不因简单相关就自动实现新颖性选择或双组扰动。本轮不训练模型、不添加约束、不运行固定后位置消融或120/900秒实验，也不重跑HighDiv。
