# 第二阶段：固定第四位置120秒最小消融冻结协议

本协议在读取本轮性能结果之前冻结。分支 `position-fixed4-ablation` 从完成第一阶段机制诊断的 `6d2cab4` 建立。用户授权的范围为原两个开发公式 × 7个新seed × 3配置 ×120秒，共42次会话。没有自动晋级门槛或自动长跑；不重跑HighDiv、不调整翻转概率、不采集完整冲突/学习子句/回溯轨迹。

## 固定配置与语义

- `first_immediate`：固定第1个支持原子；保留旧实现路径。
- `position_immediate`：每个可启用查询独立均匀抽取1–4；保留位置随机数流。
- `fixed4_immediate`：固定第4个不同支持AST原子，必须经过 `SupportedPosition::visit`，不能通过关闭随机位置跳过计数。

同一查询重复AST不推进计数，回溯/重启不重置；仍只观察原生前32次决策。未到达不补发动作。KeepNative/FlipOnce各50%，只在实际到达且通过相应预算检查后抽取。保留旧实现中抽取后的预算复核；若抽取后被预算挡住，日志记录已消耗随机数且没有实际选择。不改成按查询序号预取公共动作。旧 `reached` 字段继续表示完成选择；新增 `target_arrived` 单独表示到达支持原子位置、尚未必通过后续预算检查。

三配置均使用完整原公式、持久增量求解、完整模型阻塞、一次查询最多一个软相位、同一查询授时控制、在线合法性验证与立即交付。覆盖、去重及完整0/1观察状态仍仅按已有交付规则计入。位置机制额度仍为会话5%，即6秒；记录首次停用原因、查询、实际时刻和累计机制成本，不因后续查询改写首次记录。

唯一额外诊断为初始化参数/耗时、位置到达与动作抽取、机制成本/停用以及少量原始Z3统计。统计读取和诊断日志均占总会话墙钟；机制对象存在后，新增统计读取和诊断日志成本也计入机制额度。既有其他成本规则不变。原始计数器及相邻不下降差值仅作为低开销描述性证据，缺失、下降/重置明示，不能据此声称完整求解历史或H3因果关系。

## 输入、seed和运行安排

公式（与此前两个开发实例一致）：

| 文件 | SHA256 |
| --- | --- |
| SMT_random_LIA_ex14600_2600_100.smt2 | 114fb8ac7228c36cc6124bd9f2d95fd16a3bf2d330c39e185e8145d56821de1f |
| SMT_real_LIA_ex8500_2400_100.smt2 | 9ff3c643c1756057b1f127c5818bf38c468761ad3d2dd742cf34e3511e0690ec |

新seed固定为10、11、12、13、14、15、16；与已有0–9不重叠。每个会话120秒，包括加载、初始化、求解、验证、记录及交付。相同公式/seed的三个配置同一释放时刻并行，固定分成15、15、12个会话的三个批次，各批完整结束后再释放下一批。任务与CPU映射在 `plan.json` 冻结，不据结果调换执行顺序或CPU。

当前机器8物理核/16逻辑CPU，前两批15个采样进程使用15个不同逻辑CPU；监督器使用剩余逻辑CPU并与一个采样进程共享物理核。单例配置、物理核和启动顺序做预先固定轮换；各组三配置处于三个不同物理核。不能称为15个独立物理核。Z3的超时辅助线程与主线程均绑定同一逻辑CPU，逐线程亲和性保留。

预检至少18GiB可用内存（15×1GiB参考包络+3GiB保留），每进程地址空间6GiB、单文件1GiB；总RSS超过20GiB或可用内存低于2GiB则停止当前批次、保留失败，不换seed或自动重试。120秒后仅允许最多2秒清理，清理期间模型不能计入120秒正式覆盖。采样前结束所有构建/回归，采样全部结束后再执行15路独立覆盖审计。

## 回归与冻结证据

Release及ASan/UBSan在独立 `build/position_fixed4` 中构建；保持旧二进制、Z3依赖和历史结果哈希不变。通过现有回归，并新增实际固定4选择、重复不推进/窗口/不续发、未到达不消耗动作、旧配置操作数受限序列兼容、额度停用证据、42会话映射以及未达前缀不得替代等检查。所有构建/测试失败与修复证据保留，不用合成正确性用例作性能数据。

代码、协议、验证证据先提交，再生成输入副本与完整SHA256计划，再提交计划后启动一次。没有测试查询数上限泄漏。历史数据不修改。

## 统计口径和判断范围

完整策略为主要结果，所有未到达、未选择、Unknown、超时及零收益查询保留。附加到达率分母同时给出全部查询及可启用查询；实际选择和Flip分开。每会话成本、扫描次数/特征耗时、首次额度停用时刻/查询完整保留。

逐公式、逐seed分别比较固定4−固定1、固定4−随机1–4、随机1–4−固定1。给出7个原始配对差值、均值、中位数、胜平负、最大退步。两个公式绝对bit不合并；7个seed不是7个新公式。查询不是独立重复。

固定时间点1/5/10/30/60/120秒；精确阶梯AUC为120秒bit·秒。固定前缀1/2/5/10/50/100/1000，严格使用对应模型，未达到记NA。每个配置给出达标/未达标会话数和达标时间；配对表保留所有未完成配对，不能只给达标子集的有利结果。120秒不足以回答前1000时明确保留未知。

收益分箱固定0、1–2、3–9、10–99、100+ bit，使用真实顺序下的边际累计，重点判断固定4能否保留中小收益。初始化逐组核对相同公式、求解器类型/seed、RNG种子、首模型前状态与授时序列、首模型完整身份与时间。首次干预前模型若不同，不删除也不把其差异归因于位置。

本轮不给单一成功数字自动晋级。位置更后、到达更难和扫描成本更高可能共同改变结果。报告用实际证据指出后续值得查的因素；H3统计只能提出线索。本轮不开发新配置，不启动900秒或任何额外机制实验。
