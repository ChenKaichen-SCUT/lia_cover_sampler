# 第九轮预冻结协议

基点 af9b2c6；第八轮记录、计分、停止决定均不修改。本轮只使用既有开发案例，禁止 HighDiv 重跑、全量模型重放和 900 秒实验。正确性、机制可用性、性能分别验收。

## 离线诊断（先于任何新求解）

逐条导出第八轮 online_30s 与 mechanism_400ms 的广泛查询，包括普通回退。只填写日志直接保存或可唯一关联的信息。历史宏观实际 timeout、纯 check 时间、外部中断证据缺失时填写 unknown；每轮恰好一次宏观调用时另列 macro_solve_seconds 聚合计时作为近似证据，不冒充纯 check 时间。

固定诊断集合：仅 SMT_random，按历史所有真实宏观查询的失败次数降序、group/alternative 身份升序，选前三个已查询备选；再选 group/alternative 身份升序的前三个从未查询备选，共六个。先写 selection.json，再附见证标签。诊断模型池固定为该公式四份历史 900 秒记录各自前 100 个有原时间戳的模型，不扫描其他公式；逐模型用原评测器验证 F，按目录赋值条件具体求值。标签 NO_WITNESS_IN_POOL 只针对这个有限池。若六个均无见证，再按身份顺序补最多两个池中已知可行备选，单列正对照。生成器和实验子进程不读取模型池或见证值。

## 公共控制策略

求解器种类及主要参数、完整 F、目标编码不改。单查询级别固定 50、200、1000、2000 ms。保留 raw_status/raw_reason，另存控制分类和全部依据。canceled 且纯 check 时间至少达到实际 timeout 的 80%，无外部中断、总截止或资源耗尽证据时，标记 suspected_local_timeout（推断）并允许有界升级。超时截短不得视为完整级别失败。一般 Unknown 每备选至多一次延后重试。资源耗尽和外部取消不通过加时恢复。

备选状态与正式 visits 分离。公平配置按两次新备选、一次升级重试；队列空用另一队列；失败后至少隔一个其他备选机会（没有其他可用备选直接通用探索）。单备选四个预算级别；每级截短重试至多两次，整体尝试上限六次；普通探索达最高级别后可继续生成但受会话/查询总上限约束。排序中的算术范围仅次级。关闭默认双组组合；可显式开启用于旧作用域回归。

所有广泛动作采用相同交付预留：动作最多 2.075 秒，其中末尾 25 ms 留给内部检查点，外层另留 25 ms 最终验证输出。实际约束构造消耗也从动作中扣除。机制会话全部剩余时间可用于广泛动作；在线会话将初始化之后剩余时间的 40% 作为一次性的广泛成本额度，按实际动作完整耗时扣除，单次可连续使用至 2.075 秒，不休眠攒额度。两个在线配置同管理器；微观仍使用至多 400 ms、原窗口和至多三次查询，其余时间继续微观工作。宏观无结构时仅识别目录，直接走 plain 路径，不构造宏观求解器或消费额外随机数。

每个广泛动作默认一次查询并立即交付最佳及时见证，然后更新正式覆盖；不中途改变正式状态。每会话最多 10000 动作，停止在总截止、外部中断或安全上限。选择/约束/求解/补全/验证/写出均计时。首次、宏观、普通探索求解器独立，没有共享首次求解的学习状态；会话内各自增量复用。

## 阶段 A

固定六个备选（必要时加至多两个明确标记正对照），solver seed 0、1，50/200/1000/2000 ms。每个点独立进程、独立 Formula/目录/宏观求解器，完整记录冷启动及动作成本。固定 timeout 仅是 check 上限；附加 1 秒非求解成本余量，不把完整动作称作 timeout 毫秒。最多六路，按每个备选/seed 的四预算点成组，组间屏障。全部保存，不从结果选目标，不按结果追加预算。

## 阶段 B

SMT_random 已有 prefix-1、prefix-10，seed 0、1、2；plain_fixed、macro_budget_fixed、macro_fair_retry，18 个会话各 10 秒。三配置的普通探索都使用公共分级控制；macro_budget_fixed 保留旧 visits/算术范围排序，只加每备选预算反馈及有界尝试保护；fair 再加公平队列。两种宏观均优先当前模型不满足的单备选。种子正式纳入 S0，随后每次正式写出立即更新覆盖与去重。

每批包含两个完整三配置组（六进程），批间屏障，组内模式顺序随 seed 轮换。不进行并发校准，记录 UTC 起止、进程 CPU/墙钟、调度组和环境。审计只在采样全部结束后执行。计时从文件加载前开始，初始化每会话一次。零输出、超时、失败全保留；前 1/2/5/10 个新样本未达时填缺失，不拿部分前缀冒充完整前缀。

进入 C 的预先量化门槛：正确性全部通过；fair 配置至少两个不同 solver seed 有及时、合法、不同且正增益的宏观正式候选；相对 plain 的六个配对中，累计覆盖严格胜出的配对来自至少两个不同 seed，六对平均差 > 0、中位差 >= 0。不同快照/seed 仍只代表一个公式。只看 A 的 SAT 或见证正对照不允许晋级。

## 条件阶段 C

仅 B 达标后运行三个既定开发公式 × 三种子 × micro_plain/micro_macro，各 30 秒，共 18 会话。每批三个完整配对、最多六路、批间屏障，模式顺序轮换。初始模型从首次求解开始计时计入样本，全部失败保留。适用公式评估真实覆盖，不适用公式单列目录与管理开销，不作宏观收益证据。未达 B 门槛不启动 C，不自行增加实例/预算。

## 验收与统计

Release 与 ASan/UBSan 回归，合成可注入结果验证取消、资源、截止、截短、连续 200 ms 成功、队列公平、透明回退、证明作用域、及时见证保留/迟到排除。性能前原评测器差分通过；非法模型/错误覆盖/错误缓存/倒签立即停止并修复。

独立审计使用冻结原始 Manual 评测器，仅解析求值，不进行新搜索，验证正式连续完整 seen 状态、去重、候选条件、检查点与输出时间。保存逐查询、逐候选、逐会话、配对及均值/中位数/胜平负/失败；主比较以会话为单位。来源只是保存查询关联，不作模块独立因果归因。B 的三配置区分预算修补与队列增量，但无冻结旧版同条件新跑，因此不能精确量化相对旧实现的因果速度提升。
