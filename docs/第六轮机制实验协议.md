# 第六轮：目标先行的变量块候选合成，事前协议

基线为 `5ed367c`，独立分支 `round6-coverage-block-generator`。仅实现独立模块、合成正确性测试和少量已有开发快照配对。保留 A/B、覆盖口径、原公式验证和全部冻结结果，不重跑 HighDiv，不改 polish、准备缓存或复杂调度，不启动端到端实验。本轮是待验证设计，不预设性能优势或独立创新性。

## 对照及共享机制

两侧都调用现有 `Global::query()`，共用原有 Reach、精确无界整数 LIA bit 编码、增量求解器、目标冲突缓存和未知状态分类。仅扩展该接口以支持具名的变量固定／模型排除 assumptions，并区分冲突作用域。原始 `restrictions=nullptr` 查询路径仍存在，既有调用默认不加新限制，冻结 A/B vendor 不变。

共享选择器在有限随机候选池中优先选择已有相反观察、命中即产生覆盖的目标，再优先原 AST 变量节点；同一快照、target seed 产生相同主目标。首次观察目标单独标记。目标选择器不按案例定制。双方共用主目标后的至多 3 目标相关包构造和冲突删目标逻辑，不执行 MaxSMT；实际增益用全部正式覆盖计算，目标数量不是收益。

变量块模式在目标表达式、Reach 所需条件变量和有界相关必要等式依赖上形成初始块。只把沿顶层合取必真的等式用作协同释放提示，不把条件分支等式当作永久约束。必要合取的前置条件由 F 保证，依赖遍历可跳过这些恒真条件；初始依赖不完整只影响效率，不能据此简化完整 F。依赖操作上限 2,048，相关等式分析另外最多 2,048 个依赖操作，每轮协同新增至多 8 变量；不建立全系统依赖闭包。

块外变量以新鲜 assumption 固定为本动作种子值；种子排除用另一类 assumption，两侧相同。固定条件触发 UNSAT 时按原始变量的固定索引顺序，每次最多释放 core 中 2 个变量，再有界协同释放。最多 3 次冲突扩张，规模上限 `min(n,max(8,min(64,floor(n/4))))`；到界或受限查询 Unknown 时允许同预算内转成全局查询。局部或排除模型条件参与的 core 不进入全局缓存。无额外条件的目标 core 才能缓存。Unknown、Timeout、ResourceExhausted 和预算退出不构成不可达证明。

只输出不同于种子且不在已正式输出集合中的完整合法模型。它是新增样本，对 S 的真实边际覆盖直接作为收益；**不减去种子自身的 gain，也不要求保留种子的观察**。正式 S 从始至终不变。全局对照同样排除种子，使用相同去重与验证规则。

## 预算和交付检查点

唯一性能预算为双方每动作 **60 ms**，最多 6 次查询、目标包最多 3 个，不安排较长预算补跑或参数搜索。整个动作共享计时，目标选择、依赖、约束构建、编码、求解、模型补全、完整 F 验证、覆盖评分、分支比较及检查点写出全部计费。预留 `max(2 ms,20%动作预算)` 用于验证／交付；搜索子预算是余下时间，所有重试受同一父预算约束。求解仍沿用 Global 的 timeout 状态及剩余预算截断。

每次更好候选在原公式、目标 Reach／bit 和去重检查后复制并写出完整检查点。只承认预算内完成写出的检查点。后续超时、Unknown、冲突或迟到候选不覆盖先前的及时见证；超时造成的实际总成本完整记录。无及时模型的收益为 0，无候选调用保留。此口径与第五轮“动作结束后才核验输出”的规则不同，是本轮明确要求的先保存可交付见证；双方一致。

## 生命周期及固定测量规模

使用第三轮已有开发快照的 **prefix 1、10**：Bromberger、SMT_random、convert，共 6 个快照，不新增状态。每个快照，solver seed 0／1／2，成对重复 2 次，两个模式各一个独立子进程；每会话同一 F、Global 求解器、S 和种子连续做 3 个动作，target seed 为 `3*solver_seed+action_index`。

共 **72 个会话、36 对会话、216 个动作、108 对动作**。每对版本先后串行执行，按快照序号＋solver seed＋重复号奇偶交错顺序。固定最多 15 槽，OMP／BLAS 单线程，不重新校准并发。所有计时会话结束后才启动独立原覆盖审计。

公式初始化、前缀恢复验证及引擎初始化只计一次，单列且不免费。每会话的总成本包含一次初始化、三个动作和日志处理；外部另测完整进程墙钟及逐 PID CPU。动作指标之外报告“初始化＋动作”和完整会话收益／成本；不将离线前缀恢复重复收取三遍，不将一次初始化排除后宣称整个方法更便宜。两侧都用相同新建 Global（含其现有两个求解器），会话起点没有额外预热或已学子句。

## 审计、报告和继续／停止规则

记录初始／最终块大小、每个释放变量及原因、query 状态与实际目标、局部／全局 core、实际 timeout、跨原分支情况、每个检查点原模型、首次正增益时间、预算内最好真实覆盖、全成本阶段和失败率。用冻结的原覆盖评测器独立核对全部检查点和最终候选的 F 合法性、去重、原 S、真实边际 gain 和截止；只加载评测模块，不运行 HighDiv 采样。

每个“快照×solver seed×动作序号”的两次重复先平均，共 54 个描述性组合；不把重复或同一会话的三个动作当作独立随机样本，不据此声称统计显著性。必须报告每案例／状态和所有零结果。

后续集成需满足下列之一，且全部审计通过、无候选比例不增加、至少两案例和两快照支持，不能只由单一状态驱动：

1. 配对组合的真实新增覆盖平均差为正、中位数非负、至少 2/3 组合非负；会话均值的覆盖／完整成本也改善。
2. 所有组合的覆盖非劣，双方具有相同正覆盖收益的组合中，平均动作成本至少降低 15%，并且包含初始化的完整会话成本也至少降低 15%。没有正收益的调用不能用来证明“同覆盖成本更低”。

这只是本轮小样本的继续研究门槛，不是性能优势的普遍证明。若不满足，停止扩展；不增加目标包、查询次数或预算补救。即使满足，本轮也只给继续建议，不自动启动 A/B 集成或长实验。
