# 第八轮离散选择结构分析

ChoiceCatalog 只遍历根的 AND 必要路径并提取常量等式及其 AND。一般 OR 不作 XOR；仅当每对备选存在冲突赋值才标 exclusive。实际模式为所有满足备选的集合。必要等式仅作为静态变量关联范围，不把选中分支当全局约束。算术范围是语法祖先范围，不是已证明会改变的节点集合。

统一上限：50,000 个必要路径节点、200,000 次遍历操作、512 组、16 个备选、每备选 64 个赋值，静态工作预算 100 ms。超限保留可靠已识别组并标 incomplete，不枚举组合。参数在新模型实验前确定；这些轻量特征不宣称能预测性能。

每个备选要求变化的坐标数应相对具体模型计算，不能把组大小一律写成必须移动数；机制日志会报告 forced_changes。完整公式决定必要等式如何协同，语法关联数并非方程秩或自由度。历史正式模式来自 early_modes / 全流模式哈希，可与目录编号关联。

SMT_random/prefix-1 在第五轮相同快照较长预算对照中双方各九次确认当前 safe 区域零维（见 docs/第五轮实验报告.md），不是全局无解。LineDomain 和方向移动受该区域分支等式约束，无法凭缓存或更长方向步长离开零维区域；原 Global bit 查询保留完整 F，理论上可以跨越，但精确模编码、Reach 与算术耦合可能提高求解成本。本轮只把离散选择查询作为待检验替代，不预先解释 bit 查询超时的因果。

真实 bofill 公式来自本地 HighDiv 原始 LIA_bench，路径和 SHA 保存在 bofill_catalog.json。它只作额外静态结构诊断，不加入九案例性能表或三开发实验，更不以合成数据冒充真实 benchmark。对其他没有可靠组或静态分析不完整的结构，通用探索保留。

重放：`HIGHDIV_ROOT=/tmp/lia-highdiv-frozen /tmp/lia-highdiv-frozen/venv/bin/python3 scripts/analyze_early_coverage.py --output results/round8_analysis_replay --jobs 9`，随后 `scripts/analyze_plateaus.py --input results/round8_analysis_replay`。输出必须新目录；所有历史原始文件只读。

在三个开发案例中，仅 SMT_random 有本轮支持的目录（114 组，约 35.1% 为多变量组）；Bromberger 与 convert 的这类目录为空。六个评测案例中 SMT_real 和额外静态 bofill 有 85 组。该适用性限制在新实验前已知，不能以合成例的成功泛化到全部结构。
