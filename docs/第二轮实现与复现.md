# 第二轮实现与复现

本轮基于 45faca0f71c83de53c92ed82b4fe9fa2e96676e6，在 round2-control-and-lines 分支实现。原始覆盖口径、HighDiv 基线、原 LIA 样本和依赖记录保持冻结。新指令见 [指引第二轮.md](指引第二轮.md)。

## 实现

1. **控制修复**：TargetSolve 和 Explore 分别维护超时、未知结果、资源耗尽、连续快速 SAT、累计成本与冷却状态。实际查询预算取请求值、动作剩余和全局剩余的最小值；探索阻塞使用完整赋值去重。探索上下文 UNSAT 与原公式目标证明隔离。accept 返回正式提交的增量，各来源统一汇总，零增益填充不重置覆盖停滞。
2. **动作调度**：LocalSafe、LocalLine、TargetSolve、Explore 每次选择一个动作。完整父动作成本单列，失败调用也参与收益率。先平滑收益、成本、数量再计算 R/Q。探测使用实际耗时额度；低收益暂时冷却。Q 调节单模型改进预算，改进自身的连续零收益也触发冷却。冷启动同等优先级先尝试探索。新不同模型的零收益输出采用较短冷却，覆盖增量仍为零。
3. **方向与目标**：安全区域和结构等式分别标记作用域。坐标、等式关联核、多自由变量组合、验证过作用域的历史差分按配额轮转；组合从全部自由变量抽取。稀疏精确消元有运算和整数长度限制，未完成时记录秩未知。目标选择结合变量依赖、观察状态、历史成本和真实轮转游标；全局单目标不可达证明提前过滤，覆盖分母不变。
4. **LineDomain**：只提取顶层合取中的全局仿射整数等式。固定 Boolean 变量，在原始 DAG 上精确计算不交闭整数区间并集，使用可空端点表示无穷；支持交、并、补、严格比较、整除性和负系数。先求可行且可观察集合，再剔除 z=0、裁剪无界分量的周期窗口并做模命中。数值为常数但 Reach 改变的机会和 Boolean 观察目标也参与。算术 ite、其他不支持操作及分析超预算均显式返回状态，交给其他动作继续。
5. **单模型改进**：冻结正式覆盖，只比较每个完整候选自己的边际覆盖；每次移动后重建 Region/LineAnalyzer。移动步数、不同候选数、时间同时受限。正式覆盖只接受最终模型。所有来源共用改进接口，初始模型及时输出。
6. **目标包修复**：在一个动作预算内最多 4 次查询、2 次扩充。UNSAT 删除实际 core 中一个低排序目标并保留其余目标；多元素 core 不禁用单个目标。SAT 保存最好完整见证，后续超时仍可返回此前见证。包大小参考真实覆盖和耗时。注册数量、商变量、缓存检查成本、单目标证明和多目标冲突分别记录。

来源记录含 seed_origin、parent_seed_id、refinement_modules，以及原种子保留、局部新增、局部丢失的真实 bit 集合计数。正式新增覆盖满足 retained + added = final_gain。来源归因和关闭模块的消融是不同证据。

## 配置

| 名称 | 启用内容 |
|---|---|
| control_ab | 独立阶段一二进制，仅 A/B 控制修复 |
| schedule | A/B + 新动作调度，原局部方向生成 |
| directions | 增加方向配额、公平候选和目标匹配 |
| polish | 再增加单模型改进 |
| line | 再增加结构等式和 LineDomain；等价于完整版本关闭 repair |
| full | 全部机制，包括目标包修复 |
| no_line | full --disable line |
| no_polish | full --disable polish |

独立开关：--disable quotas,fair,matching,polish,line,repair,scheduler；--scheduler legacy 保留旧调度。预算开关包括 --direction-cap、--candidate-cap、--attempt-cap、--polish-steps、--polish-ms。默认方向上限 20、不同候选上限 24、尝试上限 256、改进 6 步/60ms；改进不同候选上限跨移动累计。LineDomain 默认 512 个区间、50000 个 DAG 节点、200000 个仿射项、4096 bit 整数。实际配置写入每次运行的 config.json。

## 复现实验

当前机器使用 /tmp/lia-highdiv-frozen 的冻结 Z3；其他机器按 README 构建依赖并替换路径。以下命令运行新算法，不启动 HighDiv 或原 LIA。

~~~bash
cd /mnt/Space0/SMT_Sampling/lia_cover_sampler
export HIGHDIV_ROOT=/tmp/lia-highdiv-frozen
LIA_PYTHON="$HIGHDIV_ROOT/venv/bin/python3"

# 仅完整版本：每案例两次独立实验，共用一个 12 槽队列。
python3 scripts/run_round2.py \
  --binary build/lia_cover_sampler \
  --configs full --split all --seconds 900 --jobs 12 \
  --output results/round2_next

# 完整模型验证、原始覆盖率逐前缀复算、每次运行前 5 个完整状态差分。
"$LIA_PYTHON" scripts/audit_round2.py results/round2_next --jobs 12

# 读取保存的旧 LIA 和 HighDiv 对照，不重新采样。
python3 scripts/analyze_round2.py results/round2_next \
  --output results/round2_next_analysis
~~~

运行八个配置时省略 --configs，并提供 --control-binary。阶段一必须独立构建：

~~~bash
git worktree add --detach /tmp/lia-round2-control 1ceceff
cmake -S /tmp/lia-round2-control -B /tmp/lia-round2-control/build \
  -DCMAKE_BUILD_TYPE=Release -DZ3_PREFIX=/tmp/lia-highdiv-frozen/venv
cmake --build /tmp/lia-round2-control/build -j 12
python3 scripts/run_round2.py --binary build/lia_cover_sampler \
  --control-binary /tmp/lia-round2-control/build/lia_cover_sampler \
  --split all --seconds 900 --jobs 12 --output results/round2_next_all
~~~

队列为每个配置生成 time 与 count 两组目录：time 的数量上限为 4294967295，count 为 1000，两者时间上限均为 900 秒。初始可同时运行 9 个 time 和 3 个 count，任一任务结束立即取下一个，不等待某批全部结束。输出目录存在时拒绝重跑。单求解器计算使用一个线程，Z3 的计时辅助线程不构成额外求解并行。

每个子批次记录输入、可执行文件 SHA-256、完整命令、起止时间和退出状态；根目录保存统一 plan.json 与 queue.jsonl。严格墙钟从创建进程前开始，到截止时终止进程组，只统计完整写出且时间戳在预算内的模型。没有达到某个前缀数量时标记缺失，不补齐或外推。

审计完成后，可用 scripts/package_results.py 逐批归档 raw；archive.json 记录压缩包和各成员哈希，打包后重新读取验证，不删除原目录。新分析不重放旧 filter，省去无关成本，原始合法性和覆盖检查仍完整执行。

## 回归与统计解释

核心测试验证独立超时增长、重复阻塞、正式进展、调度成本与冷却；search_test 验证关联等式方向不被自由变量挤掉、候选公平、协同完整模型、区域重建和归因；line_test 验证 {0,10}、无界大周期、负系数、Boolean/Reach 域及预算状态，并与原公式 Z3 和原遍历比较；repair_test 验证三目标冲突、任意两目标兼容、后续超时保留见证和共享查询上限。Python 集成测试覆盖所有 profile 的合法性、唯一性和原始评测差分。

summary/progress 的 action_seconds 是父动作成本；seconds 是细分阶段；refinement_seconds 是嵌套改进成本，三者不能相加。硬截止时 progress 统计是最后一次检查点，只能视为轻微截尾；完整输出文件及审计前缀是覆盖和数量的依据。

本轮没有实现分段仿射算术 ite、完整整数核生成、全局 MaxSMT 或完备无限域枚举。单种子结果只能描述该次运行。旧基线与新实验并发负载、编译优化级别的差异必须随最终结论一起披露。
