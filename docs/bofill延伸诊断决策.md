# 30秒诊断后的固定决策

40次诊断完成后、120秒延伸启动前记录：SMT_random 的 choice_only/full，在两种控制和两个seed中都没有30秒内及时见证；其他三种表示均有见证。SMT_real 的 choice_only/full 均显著晚于原式；eq_only 也没有跨实例稳定首次求解优势。

30秒已将主要嫌疑指向整数选择表示，而非仅仅2秒取消，但无法排除更长连续查询在原冻结实例上的改变。按启动前协议，唯一延伸为 SMT_random seed0、plain/full、continuous，各120秒，总共两次。二者使用与40次诊断相同二进制、Z3、求解器和完整计时口径。其收益只能按相同120秒总预算比较。失败不再延长。

不晋级五种变换的60秒采样。没有稳定 first-SAT 优势时，不继续增加消元额度或增量消元复杂性。联合 DAG 扫描占用主要 tick 额度，但不是编译墙钟的最大单项，消元本身也尚无求解优势，故不实现增量工作队列。

下一项代码变更仅为指引要求的实验性10秒首次模型保护：若编译阶段未交付模型，丢弃编译求解器、在原总预算剩余时间中恢复原式。保留 plain 默认主线。保护的正确性回归与编译性能收益分开，不宣称其本身是一项更优采样策略。
