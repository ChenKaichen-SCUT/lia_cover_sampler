# 覆盖软偏好实验协议（先冻结，后运行）

基点 `07098bc`；分支 `coverage-soft-phase`。两个输入为 benchmarks 中的 SMT_random_LIA_ex14600_2600_100.smt2 和 SMT_real_LIA_ex8500_2400_100.smt2。它们是已接触的开发实例。HighDiv 不执行，旧结果不作本轮配对数据。

三个模式 plain / random_soft / coverage_soft 使用同一入口和同一份独立补丁 Z3。原公式持久 simple solver；只添加正常的完整模型阻塞。首模型无干预，所有及时不同合法模型均正式输出。查询采用既有固定 50/200/1000/2000 ms 重试级别，同一个总会话截止；预留 25 ms 交付。偏好自身没有额外求解调用。

固定参数：摘要分析最多 1 秒、2,000,000 操作、64 个组、200,000 条稀疏节点观察；ChoiceCatalog 原有更小的识别上限仍有效。日志和反馈更新也计入会话时间。每次 check 最多实际覆盖 8 次相位；一个原子和来源组最多一次；64 次冲突后停止干预，内部重启不重置。随机偏好使用独立 mt19937_64(seed XOR 0x935602ab7d)，不消耗原生随机流。coverage 分数按 guaranteed covered 缺口、再新 0/1 观察字典序；完全相同不提出偏好。两种 soft 模式共用目录、摘要、映射、额度及生命周期，不人为配平实际介入次数。

先通过正确性回归、Release 及 ASan/UBSan，再运行功能曝光：两个实例、seed 0、三个模式，各 30 秒，共 6 会话。只检查完整模型合法性、摘要条件、日志、预算和实际介入，不根据覆盖结果调整参数。若两种 soft 在真实输入中均有实际覆盖且无正确性问题，进入正式筛选；若某实例没有实际介入，定位映射或明确不适用，不能把空运行扩为性能结论。

正式筛选固定两个实例 × seed 0/1/2 × 三模式，共 18 个 60 秒会话。不自动启动 900 秒。固定 CPU 0、2、4 三个不同物理核，每批同一实例同一 seed 三模式同步启动，批次屏障，按批号轮换核心。控制器在 CPU 6。采样期间不构建、不审计、不运行其他实验。独立冻结评测器审计在所有采样结束后执行。每进程单线程、地址空间 6 GiB、单文件 1 GiB，外部截止终止，最多 2 秒清理。全成本从同步入口计时，包括解析、初始化、首模型、分析、查询、验证、记录及阻塞。

预先冻结判断规则：

1. 正确性与生效是前置条件；失败或零介入不能声称性能验证通过。
2. 逐实例比较 coverage−plain、coverage−random、random−plain。一个实例的“可重复正信号”要求 coverage 最终 covered 在至少 2/3 seed 同时严格优于 plain 和 random，且两项配对差中位数均为正。
3. 候选供给保护：coverage 的原始合法模型/秒中位数至少为同实例 plain 的 90%，同时展示绝对数量和每 seed。
4. 早期风险：前 2/5/10/50/100 个原始样本只在双方达到时配对；至少两个共同前缀各在至少 2/3 seed 退步，记为反复早期退步。不足输出数标未完成，不补零。
5. 新增分析、反馈、安装、钩子查表与钩子日志成本合计中位数若超过预算 10%，标为成本风险；全成本仍报告，热路径计时已包含在 check 中，不重复相加总墙钟。
6. 若两个公式均有可重复正信号、无上述供给/早期/成本风险，才建议下一次独立验证；一个公式满足，只报告有限正信号并提出独立实例验证。若已实际生效但没有上述信号，停止扩大；不增加强度、摘要大小或调度补救。随机与 coverage 同样改善不支持覆盖反馈独立有效。

原始模型轨迹、完整覆盖状态、前缀/时间指标、新观察派生序列分开报告。新观察派生序列仅离线提取，不改变搜索。截止时仍未恢复的高原标为右删失。每个最终满足可靠相位的模型检查 G 包含关系及该相位 L 下界；不同相位收益不得相加归因。失败、零输出与 Unknown 全部保留。回归和功能结果不能冒充 60 秒性能结果。
