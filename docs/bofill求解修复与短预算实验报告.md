# bofill 求解修复与短预算实验报告

**No-Go：本轮没有符合晋级条件的性能修复候选，不执行60秒在线采样。** 40次30秒诊断和预选两次120秒延伸已完成，原式仍是默认主线。这个结论不改变上一轮900秒报告，也不把历史HighDiv当作本轮配对。

## 实施的有限修复

保留五种独立可测表示，新增固定10秒首次模型安全回退，使用显式 `_fallback` 模式启用。10秒包括载入、编译、所有准备、求解、完整恢复、验证和交付；编译首模型若未及时写出，销毁编译求解器，在原会话剩余预算内重建原式求解器。保存已交付的完整原赋值，重建时逐个阻塞。覆盖和正式去重对象独立于求解器生命周期，保持连续。

模型和查询记录区分编译表示、plain_fallback 与 plain；汇总分开报告输出数和覆盖贡献。原式回退产生的收益不会归因于编译器。回退不是新生成算法，不使用历史模型，也不重置时钟。见 `bofill安全回退说明.md`。

没有引入增量消元、更多q编码、投影、宏观指定分支、变量块扩张或额外调度。联合扫描消耗的工程tick很大，但 native simplify 的实际墙钟更高；单独消元没有稳定跨实例求解优势，继续把扫描做快不能据此声称采样性能已修复。指引情况A第4项要求在此停止消元优化。

## 验证与边界

Release 和 ASan/UBSan 各自17项C++、135项Python回归全部通过，完整记录位于 `results/bofill_fix_validation/regression/`。新增覆盖五种表示隔离、保留显式OR、不偷偷消元、原变量恢复、完整有限模型集合、真实20个历史见证×5模式、冻结旧full映射逐字一致、两种首次查询控制的同预算与无剩余预算处理、固定10秒首次模型保护、回退后的覆盖与完整身份/阻塞连续、原始覆盖差分以及Unknown/取消分类。回退测试用合成公式及预推进单调时钟验证边界，不伪装成真实实例在线性能实验。

没有进行60秒会话，所以首次模型以后的新样本数、前2/5/10/50/100模型覆盖、60秒累计覆盖和新的在线高原均**无实测值**。不能补零、不能从首SAT推断吞吐，也不能把回退后的普通探索潜力写成已证实的覆盖优势。`decision.json` 明确记录零个60/900秒实验和零次HighDiv运行。

## 覆盖重复仍是独立问题

新的42个首次SAT探针共有33个及时合法见证，每会话最多一个。它们的首个模型 covered-bit 收益为0，已保存首次观察数、Boolean/整数分项；没有前一个模型或近期窗口时，变化变量数和近期观察重复率留空。前2及更大前缀标记未完成，不能把不同控制/seed的独立首模型串成采样轨迹。详见 `results/bofill_diagnosis/observation_analysis/`。

只读旧900秒独立审计显示：plain 的 random 零增益模型占94.70%–96.16%，real占96.09%–97.15%；最长零增益段分别159–192及288–335个模型，最长无覆盖增长约122–149秒及143–160秒。完整赋值不同，不意味着原始AST获得相反bit观察，故更多 SAT 不直接等于更高覆盖。

另作固定的离线见证核验：以旧 plain seed0 的最终覆盖为基底，按seed1前10个、seed2前10个的固定顺序读取历史合法见证。random的20个见证各自仍有正收益，单个最多82 bit，按顺序真实合并的总额外覆盖为113 bit；real同样20个均有剩余收益，单个最多31 bit，真实联合额外覆盖50 bit。独立收益没有直接相加，完整 seen0/seen1 按顺序更新。说明旧高原仍有合法覆盖缺口，不是所有可达覆盖都已穷尽。这是历史模型的离线集合价值，未向新探针提供提示，也不是新在线策略的性能数据。

## 后续决定

本轮只保留 plain 默认路线、编译正确性代码、诊断证据和实验性安全回退。停止当前选择算术化/消元表示优化的性能扩展。不为负结果追加预算，不提交900秒验证计划。真正的互补覆盖仍需独立研究，但本轮不启动新的候选生成实验。
