# 第七轮实现与回归验证

基于 b2f3047。新增独立 `residual_online_probe`，原 `coverage_block_probe` 及旧结果保留。入口与目标定义使用同一份常驻原公式；种子验证后先纳入 S0；每条及时正式输出立即更新完整观察、去重、覆盖版本和累计边际。

新增 `Global::query_at_least()` 使用原 `ensure()` 的单向激活与精确整数目标编码，通过临时作用域的数量阈值选择兼容目标。旧 `query()` 和 `repair()` 函数体逐字不变；只在共用 `ensure()` 的新定义构建上增加计时，包含原 repair 内部扩充带来的实际准备成本。阈值 UNSAT 使用独立记录，不污染固定目标合取的冲突缓存。候选比较基于全部 AST 边际；目标选择变量个数仅作诊断。

正式输出是完整模型行，提交回执关联真实 flush 完成时间。内部检查点可以在后续失败后保留，但不能给迟到正式输出回填时间。提交后才更新状态，最后验证边际总和等于最终覆盖减 S0。文件级写失败会导致异常退出，不继续搜索；已有完整文件保留。独立审计拒绝缺失或矛盾的来源和时间记录。

验证结果：

- Release：11 项 C++ 测试和 81 项 Python 测试全部通过。
- 最终日志时间一致性与晋级规则补充检查：15 项测试通过。
- ASan + UBSan：11 项 C++ 和 81 项 Python 测试通过，泄漏检测开启。
- 初次 ASan 使用快速 malloc 栈展开时只显示 Z3 分配顶层，无法匹配既有外部泄漏抑制。启用 `fast_unwind_on_malloc=0` 后，两个相关测试分别仅匹配既有 `lp::dioph_eq::imp::imp` 的 32/64 字节已知泄漏；保留初次失败、完整栈匹配和最终日志，没有扩充抑制范围。
- 对冻结基点中的 2399 份历史结果、报告、依赖和相关源码进行 Git blob 校验，全部未改。原第六轮归档二进制哈希也不变。

新增回归覆盖固定合取与兼容阈值的差异、所有有限三变量子窗口的阈值枚举、单向激活不等于目标真值、真实边际优先于窗口分数、直接跳过已满足阈值、版本与正式覆盖更新、Reach/首次观察配对、独立状态副本、作用域退出、Unknown/资源耗尽不产生证明、后续失败保留见证、迟到检查点/正式提交排除、种子已提交、重复模型、类型/完整性校验以及负 90 位整数。晋级规则另外用合成数据测试，确保单案例改善或早期质量退步不会被终点胜利掩盖。
