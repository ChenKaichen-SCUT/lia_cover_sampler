# bofill 实现与验证记录

本记录为正式900秒实验启动前的验收，不是性能报告。

- 冻结基点 c758fadb；投影清理独立提交 5426b07；等价编译与双向恢复独立提交 dc92ee8。
- Release：16/16 C++ 通过（新增编译测试包含21个模型集合/结构案例）；全部128项Python通过，随后新增迟到/缺时间戳/重复/尾行审计案例，最终9项针对性测试全部通过。独立Python案例共129项。
- ASan/UBSan：同样16/16 C++、128/128全套Python，以及最终9/9针对性测试通过。只复用既有冻结外部Z3泄漏抑制；没有为本轮新增代码添加抑制。外部Z3本身仍是原冻结库，不宣称把它重新做了完整Sanitizer编译。
- 清理后第十二轮45个历史会话的只读离线复核通过；在临时复制品上执行，历史归档不变。
- 两个真实公式×三个配置，各3秒，仅作合法性、结构边界、记录/截止检查。六条轨迹共77个及时不同合法模型，独立冻结ManualSatisfiesMetric逐模型检查通过；新入口逐模型覆盖增量、seen0/seen1指纹及最终完整状态一致。短跑不属于正式配对数据，不据此取消900秒实验。
- 常量选择名字碰撞回归最初发现 fresh API 与显式声明 lia_choice!0 同身份；实现已增加真实身份检查，完整模型集合回归通过。原AST没有修改。
- 审计新增观察数按冻结定义统计两种取值各自首次观察，即 popcount(seen0)+popcount(seen1)，不是只统计 union 位。独立覆盖covered始终是两者交集；所有最终状态比对通过。
- HighDiv外层实际命令 -O3 -DNDEBUG -Wall -std=c++20，冻结原源仅插入样本flush及CLOCK_MONOTONIC写完时间记录。补丁、原源/修改源/程序/Z3哈希、实际compile_commands、编译器和GMP版本均归档于results/bofill_validation。
- 三物理核监督器独立截止；进程内存6GiB、单文件1GiB作为共同安全上限。每秒读/proc记录资源，GNU time能提供退出统计时也保存；控制进程在其他核执行。任何非截止异常退出会停止后续组，保留现场，先查明资源或实现问题。

可复放命令见scripts/test_bofill_build.sh及实验协议。源文件中的未归属成本不当作免费：端到端墙钟包含初始化、编译、记录、覆盖状态复制、去重、阻塞和失败查询。结构导出用一个仅序列化的临时solver，不调用check；真正搜索从首次SAT到枚举结束共用一个持久solver。

启动前用户进一步明确HighDiv不用跑、直接引用之前覆盖率：正式队列由18次改为12次，仅plain_clean/choice_compiled。已完成的HighDiv Release构建和两次3秒验证作为原始工作记录保留，没有启动HighDiv 900秒。历史参考固定为原highdiv_time900（seed 0、外层-O0），不混入新配对统计。

随后用户要求15线程并行：保留已在跑的两个进程，新增十个任务同时执行；没有中断重跑首组，没有启动HighDiv。采样二进制保持不变，仅改变监督队列和亲和性；不在采样期间构建或运行大规模测试。记录旧、新监督器及实际并发变更，最终报告披露首组经历的负载变化。
