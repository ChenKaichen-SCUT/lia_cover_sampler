# bofill 首次求解诊断冻结协议

基点 `a31e91e`；本轮分支 `bofill-compiler-diagnosis`。旧900秒结果和历史报告只读。HighDiv 不运行。实验分阶段，不自动执行900秒或其他预算扩张。

## 正确性与表示

五模式为 plain、simplify_only、eq_only、choice_only、full，choice_compiled 仅为 full 别名。所有表示使用原式 AST 评价。eq_only 直接从原式的顶层必要等式开始，不经过选择编码；保留显式析取，不引入 q。现有单位消元的替换会简化受替换子句，不把析取中的等式当成全局必要等式。choice_only 不执行单位消元。full 保持冻结的候选条件、顺序、操作上限、恢复和全局 simplify，须与保存的编译式、改写序列和完整恢复映射逐字核对。

历史正确性见证固定选择两个公式 plain_clean、seed0、正式序号1–10。逐原变量精确检查 F(m)、Fc(lift(m))、restore(lift(m))=m，不用于性能实验提示。结构分析和最终剩余可消元候选统计单列为离线成本；其搜索 API 被禁用。它们不参与编译结果或求解决策。

编译仍为5秒、200万原有 tick 操作，未提高限额。计时为各阶段互斥墙钟时间；原有 tick 按执行阶段归属，内部 Z3 substitute/simplify 的原生节点访问次数不可见，明确记录为表达式根调用数，不能解释为所有底层操作数。原有限额是工程计数，不是 CPU 指令预算。所有性能运行计入载入、编译、诊断记录和导出开销。

## 首批首次 SAT

2公式 × seeds0,1 × 5模式 × repeated_2s/continuous，共40次，每次总预算30秒。每个公式/模式为一个四进程同步批次，包含两种控制的完整种子配对；批次依次运行。四个物理核心的逻辑CPU0,2,4,6轮换；每进程单核、地址空间6GiB、线程环境1；控制器CPU8。不与构建、回归或审计同时运行。

同一 Release 可执行文件，冻结Z3 4.14.2、simple持久求解器、仅 random_seed 和 timeout 参数。完整计时从同步门启动，包括进程执行和所有初始化。repeated 为50/200/1000/2000ms分级，只有达到实际完整超时才升级。continuous 只调用一次 check，获得扣除已发生成本及25ms交付保留后的剩余时间。之后恢复完整原赋值、验证并写出检查点，完成时间在总截止内才接受。统计读取在保留见证之后，仍计入完整墙钟与CPU。失败不冒充 UNSAT，公共 statistics 保留实际原始键，缺项为空。

计划、输入、源码、构建配置、二进制、库哈希在启动前写入 plan.json/plan.sha256，并在启动时复核。外部监督在总预算+250ms发送TERM、+2s强制回收，仅接受原30秒内已写完的合法模型。收尾成本单列，不提供额外搜索时间。

预选延伸仅为 SMT_random seed0、plain/full、各120秒、continuous。如果30秒无法区分表示难度与取消交互才执行；不扩展其他模式、实例、种子或时长。

## 预先约定的推进规则

先按指引 A–F 判断：独立选择编码已退化时，不继续加大 q 编码；eq_only 无实际首次求解优势时，不再优化消元以寻找性能正例。重复 DAG 扫描的操作消耗与其墙钟占比须分开报告；只有确有编译工作瓶颈且变换具有求解收益的证据，才实现独立增量路径。否则保留诊断，不引入无效复杂性。

最多选择一种有清晰证据的变换或首次查询控制修复进入60秒。优先要求两个公式、两个诊断seed均得到及时见证，不能以单个成功例晋级。若仅 continuous 修复编译首次SAT，其同预算机会也给 plain。实验性安全保护固定为10秒未有及时合法首模型就恢复原式求解，所有成本在原总预算内；不把回退收益归因于编译。

条件成立后另行冻结60秒协议，2公式×seeds0,1,2×plain_clean/一种候选，最多12次，必要时另加该候选的安全回退版本，总计不超过18次。必须逐实例达到原指引全部晋级标准才可提出下一轮900秒计划，本轮仍不执行。无有效候选时明确不执行60秒，不为凑齐结果挑换模式或阈值。
