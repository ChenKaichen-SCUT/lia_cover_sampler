# 软相位评分离线诊断协议（计算前冻结）

基点 56cc9ef；分支 soft-phase-score-diagnosis。正式 18 个 60 秒会话为主，曝光 6 个 30 秒会话独立，仅核验接口与一致性。保留历史源码、补丁、归档、报告与 No-Go。只解析、具体求值和重放已保存模型，所有 Python Z3 搜索入口在求值期间禁用。不运行原测试全集或任何生成程序。

来源为冻结归档与清单；解包到本轮独立目录。以公式 SHA256 + 原 AST 前序位置 + 原表达式结构哈希识别原子。日志 original/normalized AST 数字编号仅在本进程内关联；内部规范化表达式没有保存，标未知。可解析的常量等式另给出变量/常量规范形式，不冒充内部 rewriter 输出。

按查询前已及时正式提交模型重建完整 seen0/seen1。内部候选不更新状态。用冻结 ManualSatisfiesMetric 对已保存完整赋值具体求值，低64位及短路访问不变；验证逐模型哈希、覆盖版本、边际、最终状态及原审计表。Unknown 无模型的最终真假及潜在收益为 NA，交付收益为零。迟到模型单列观察性质，正式收益零。

指标：对目录全部两侧计算 L（可保证补齐 covered 的 bit 集合大小）及 N（新增0/1观察）；主解释集合只取 applied=true 且最终实现的 H 并集，检查 |H|=L、H⊆D。提出但未介入的解释集合单列；比率仅在正式 D>0 时定义，称“已实现干预摘要的覆盖解释比例”，不得作因果归因。额外存并集位图证据供独立审计。

分类固定：L两侧不同；L相同但N不同；L/N均相同且N>0；两侧N均零。没有“明显差”的数据拟合阈值，整数L不同即第一类。方向反事实模型及耗时一律未知，关联到其他真实历史查询也不当作严格反事实。

阶段固定：首模型单列；正式位置 2–10、11–50、51–100、101及以后；墙钟 [0,10)、[10,30)、[30,60] 秒（曝光截于30秒）。查询阶段由开始时 coverage_version+1 决定，Unknown 归到当时待输出位置，不能伪造已输出样本。覆盖状态阶段由已提交版本决定，列名分别说明。

高成本预先定义为完整记录周期 ≥200ms；描述分箱 <50、50–200、200–1000、≥1000ms。q.start 在评分/安装之后，q.finished 在当前查询日志写出之前。准确保存记录内 q.finished-q.start 与 check 耗时；完整核算周期定义为前一 q.finished（首条从会话0）至当前 q.finished，归入前条日志及本条准备、求解、验证、输出和阻塞，首条包括初始化，末条后尾部开销单列。它是完整成本记账包络，不声称精确分离当前准备或某个方向的成本；周期之和加尾部等于保存的会话 elapsed。所有失败保留。方向行写“关联查询成本”；汇总始终按查询去重。

单会话 Pearson/Spearman 只在至少10个非缺失且两变量有变化的点上计算，否则 NA 并列原始行及有效点数。不作显著性宣称，不把会话内事件当独立实验重复。相关项固定为 max applied L 与周期耗时/交付增益、max proposed L 与周期耗时/交付增益。

事件截断按冻结补丁重放：前32个机会（包含其中介入）保留，其后仍保留全部实际介入。已保存事件可由之前实际采用组/原子、8次额度、64冲突门槛、原生相位推断跳过原因；遗漏的非介入事件仅由完整聚合计数扣除已归属部分，剩余标不可分解。没记录到不等于没遇到；总冲突数与事件时间戳未保存，不猜测。

目录评分按每个正式版本全目录重算，包括被过滤方向和最终状态；首模型前目录只是事后重算，不声称在线已存在。没有目录（plain）记不适用，不记评分耗尽。全L为零的区间以真实覆盖提交时间划分；保留之后恢复正分数的转移。所有方向H的并集定义目录能描述的当前缺口；摘要外缺口不等于不可达。全L归零与全N归零分开。

首模型新增观察、之后新增观察、首次访问一侧与补齐相反值分列；不从主墙钟扣除初始化。按真实进程起止及CPU拓扑列重叠区间、SMT共享与首模型时刻负载，不事后校正速度。

只新增本轮纯离线回归，覆盖提出未采用、采用未实现、Unknown、迟到、摘要重叠、平分、首次观察配对、评分恢复、事件截断、跨进程原子身份及反事实未知。本轮保持 No-Go，不训练评分器、不离线选择新相位、不启动新实验。
