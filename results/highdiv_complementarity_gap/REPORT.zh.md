# HighDiv—原生随机互补性差距分析（仅保存模型）

结论是 **A＋C，局部选集问题保留 D**：保存池里已有很强的互补模型和小集合，早期正式前缀没有把这些信息集中交付；同时，每条 native 的完整900秒池仍缺少 HighDiv 已给出合法见证的观察。**不能把早期大差距都归因于缺乏高信息量模型，也不能说重排就能补上900秒终点。** 本轮没有足够证据将 B（信息只能分散在远多于HighDiv的模型中）作为主因。

基点 `ef3e9a7`，分支 `highdiv-complementarity-gap`。协议在分析前提交为 `3aae807`。未修改采样器、概率、历史数据或历史计分；没有新模型、原公式求解、HighDiv重跑或后续实验。下文 H 为该公式唯一历史HighDiv seed；N0/N1为native_random_one两个seed；P0/P1为plain。H在两次对照中被重复引用，**不是两个独立HighDiv重复**。历史HighDiv构建和并发资源与native不同，时间仅描述保存轨迹的信息到达，不能据此做同条件速度因果归因。

## 观察结构：大跳跃并非主要靠新的未访问区域

两公式H第2个模型分别新增5192/2492个covered bit；同时首次访问257/115个Boolean节点。新增covered在random中分为原Int变量2025、算术表达式3018、Boolean149；real中分别为1012、1402、78。Int收益都在0–31位，32–63位为0。首次访问、首次单侧观察、补齐相反值分别记录，前两者没有被加成covered。

random的H第2模型相对H第1模型改变368个变量，横跨10个无条件等式关联组、118个可识别OR常量模式发生变化；real对应183个变量、8组、65个模式。例如random的xH1从0变4795、xH10从2723变0；real的xH10从800变8300，xH103/xH104/xH105从2500变0。这里看到的是多个关联组的协同变化，而不是已证明由少量变量单独导致的大收益。完整前后赋值、组成员、模式、基底哈希和确切观察差在 `representative_witnesses.jsonl.gz`、`representative_structure.csv` 和 `structure.json`，HighDiv内部生成来源写作unknown。

相邻O完全相同为0，说明不能把这些零收益事件说成“完全相同的观察模型重复”；它们通常改变了取值组合，但没有为已经累计的S补上新covered。逐事件变量名、前一模型、真实基底、new observations和gain都已保存。结构统计是相关性描述，不是生成器内部动作或变量变化的因果证明。

## 最终分类与下一阶段

| 公式 / seed | 早期前缀 | 900秒终点 | 仍未知的部分 |
| --- | --- | --- | --- |
| random / 0 | A：30秒池5模型、120秒池10模型已有强组合；极小前缀受首模型影响 | C：缺H的163个bit，含16个H前10目标 | 30秒自由5模型路径虽较差，已有固定路径证据，不能误判D |
| random / 1 | A＋D：120秒已有强10模型集合；30秒10模型与300秒50模型界未闭合 | C：缺194个bit；全池还达不到H前100总量 | 是否更少的30秒模型可达到H前10，未证明 |
| real / 0 | A：30秒池10模型超过H前10；信息并非必须分散在数千模型中 | C：缺134个bit，含24个H前10目标 | 未证明最少需要多少个模型 |
| real / 1 | A＋D：120秒已有强10模型集合；30秒10模型未闭合 | C：缺182个bit，含36个H前10目标 | 30秒池的精确10模型最优值未知 |

A的“达到”主要指总covered数量；对H同一批bit的命中和缺失始终单列。没有一条native完整池包含H的全部早期目标；数目接近不等于同一批信息。所找到的900秒自由子集用91/97（random N0/N1）和70/66（real N0/N1）个模型分别复现整条native流的观察状态，这提供可实现压缩证据，**不是最小模型数证明**。

因此下一阶段应分两条研究问题：A优先研究让互补组合更早到达，以及有等待/维护成本的有限选择；C优先沿已保存HighDiv见证定位native缺失的相反取值与进入模式。不能只增加候选池期待改善固定900秒终点。B只在有有效小集合上界或更充分集中性证据后再判断；D可先补充固定观察矩阵上的有限选集界，或补齐所需诊断证据。本轮没有自动实现任何策略，也没有启动下一轮采样。

所有及时不同模型原本都已正式输出：对固定时刻已经得到的全部模型，重排不会改变联合covered。离线挑选改变后，真实在线阻塞和学习状态也可能变化，不能假设后续仍然生成原候选流。因此本报告既不宣称离线挑选是在线成绩，也不从两条seed推出算法的能力上限。
